0. 角色骨架

  • 属性:75 HP、3 能量、起始遗物 Cracked Core(每场战斗开始 Channel 1 闪电球)。
  • 起始牌组(10 张):Strike ×4、Defend ×4、Zap(Channel 1 闪电)、Dualcast(Evoke 右球两次)—— 两个职业卡就是「造球」与「爆球」的最小教学单元。
  • 核心系统 · 球(Orb):Channel = 把球塞进球槽(默认 3 槽,从右往左排);每回合开始自动触发所有球的被动;Evoke = 从右数第一个球触发其 Evoke 效果并移除。五种球:闪电(被动:随机敌 3 伤;Evoke:8 伤)、冰霜(被动:5 格挡;Evoke:10 格挡)、暗(被动:伤害翻倍成长;Evoke:打出积累值)、等离子(被动:1 能量;Evoke:2 能量)、Glass(新)(被动:全敌 4 伤但每回合 -1 衰减至停摆;Evoke:全敌 8 伤)。
  • 新机制:Glass 球 —— 衰减型 AOE 球,需要「快进快出」(及时 Evoke);Fuel —— 0 费状态卡,由状态卡转化而来,打出抽 1 + 能量,把「垃圾状态」变成资源;Focus 双形态 —— 永久(Defragment)+ 临时(Hotfix / Synchronize / Focused Strike),且 StS2 移除了 StS1 的「永久 Focus 唯一来源」垄断。
  • 结构性特征:能力卡 21 张全角色最多;Uncommon 技能 20 张 —— 球系统的「操作卡」全部集中在中期档位。
资源轴速览:球 = 被动收益池(每回合自动结算,可 Evoke 兑现);Focus = 球的通用放大器;0 费卡 = 频率轴(Claw / All for One / Feral);状态卡 = 可回收垃圾(自塞状态换即时收益,再二次变现)。

4. 主线与构筑关键卡

4.1 球伤害轴(闪电 / 暗 / Glass)

Channel 球(Ball Lightning / Tempest / Darkness / Glasswork)→ 每回合被动结算 → Evoke 兑现(Dualcast / Multi-Cast / Shatter / Tesla Coil)→ Focus 放大
环节卡作用
闪电源Ball Lightning ★(7 伤 + 1 球)/ Tempest(X 球)/ Voltaic ★(存量兑现)/ Zap(起始)/ Lightning Rod(延迟 2 回合)高频小伤 + 被动滚动;Voltaic 是本场 Channel 过的闪电全量再 Channel —— 指数增长件
暗球Darkness ★(+被动触发)/ Null / Consuming Shadow ★(回合末自动 Evoke 左球)/ Rainbow被动翻倍成长,Evoke 时一次性兑现 —— 「存伤害」形态

构筑关键卡:Ball Lightning、Tempest、Voltaic、Darkness、Shatter、Multi-Cast、Thunder、Defragment
引擎形态:Defragment 永久 Focus → 被动球数值滚雪球 → Voltaic / Tempest 把球数做上去 → Shatter / Multi-Cast 全量兑现。球伤害轴是「被动池 + 兑现操作」的两段式,与 Necrobinder 的 Osty(纯被动)相比多了一个操作层。

4.2 球防御轴(冰霜)

Channel 冰霜(Glacier / Cold Snap / Coolheaded / Chill / Ice Lance)→ 每回合被动 5 防 + Focus 放大 → Loop 额外触发 → Hailstorm 把防御转伤害
环节卡作用

构筑关键卡:Glacier、Loop、Coolant、Coolheaded、Hailstorm、Defragment
引擎形态:Glacier 起手 2 冰霜 + Defragment → 每回合被动 12+ 防 → Loop 再触发一次 → Hailstorm 每回合全敌 6 伤。球防御轴是「挂机防守」—— 与静默者 Afterimage 同构,但完全零操作。

4.3 Focus 轴

永久 Focus(Defragment / Biased Cognition)+ 临时 Focus(Hotfix / Synchronize / Focused Strike)→ 所有球收益放大 → Hyperbeam 用 Focus 换爆发
环节卡作用
永久Defragment ★(+1)/ Biased Cognition(Ancient,+5 但每回合 -1)Defragment 是球系的地基;Biased 是「先强后衰」的双刃

构筑关键卡:Defragment、Biased Cognition、Hotfix、Synchronize、Hyperbeam
Focus 是球系的唯一通用乘区 —— 与铁甲的力量、Necrobinder 的 Osty 增幅(Calcify)同职,但作用对象是「每回合自动结算的被动池」,所以成长感最强。

7. 设计观察

  1. 球 = 零操作的被动收益池:每回合自动结算的伤害/格挡/能量,与 Necrobinder 的 Osty(拦截+攻击)、铁甲的格挡存量同构,但 Defect 多了「Evoke 兑现」这个操作层 —— 被动池(挂机)与主动兑现(操作)的两段式是球系统的核心张力。
  2. Glass 球 = 衰减型 AOE:被动每回合 -1 的衰减设计,强制「快进快出」(Channel 后及时 Evoke)—— 与 Doom 的「阈值即死」相反,Glass 是「越快兑现越强」的时效资源。
  3. 状态卡 = 主动制造的垃圾:其他角色被塞状态是惩罚,Defect 可以自己塞(Overclock / TURBO / Fight Through)然后用七条回报线二次变现 —— 这是「垃圾经济学」的最完整形态,也是无限引擎的温床。
  4. Focus 双形态:永久(Defragment)+ 临时(Hotfix / Synchronize)并存,配合 Biased Cognition 的「+5 但每回合 -1」—— 「用未来换现在」的句式在三个角色里反复出现(Neurosurge 自 Doom / Borrowed Time 透支 / Wraith Form 减敏捷 / Hyperbeam 减 Focus),说明这是 StS2 设计团队的核心偏好。
  5. Common 攻击全部附带 Channel:12 张 Common 攻击里 8 张产球 —— 入口卡把「造球」做成攻击的附属动作,让新玩家第一回合就理解被动池的价值。
对 OneDeck 的参考:① 「被动池 + 兑现操作」双段式(球 ↔ Osty ↔ 格挡存量)是防守资源进攻化的三种解法;② 自塞状态的「主动垃圾」设计让 debuff 类卡牌从惩罚变成资源,可借鉴为代价型卡的标准句式;③ 衰减资源(Glass)与阈值资源(Doom)、存量资源(Soul Storm)并列,是条件收益的三种时间形态。

3. 构筑轴识别

3.1 弹药武器轴(身份轴)

reload 供给(Powder Horn / Ramrod / Port / Captain's Quarters) → 弹药消耗武器(Rifle / Repeater / Blunderbuss) → 暴击自装填(Revolver / Throwing Knives) → 封顶(The Boulder / Ballista)
入口:reload 件与弹药来源。兑现:消耗子弹的武器,单发 20-120。封顶:The Boulder / Ballista——一次填弹 = 一次巨型火力。
桥:Incendiary Rounds / Dive Weights / Captain's Quarters。密度:Ammo 相关13 件 = 9%——全池最厚轴,Vanessa 的身份正身。

3.2 水生友军控伤轴(身份副轴)

Jellyfish / Pufferfish / Catfish / Yeti Crab(友军状态施放) → Haste 触发链 → Shipwreck(+1 Multicast,封顶) / Slumbering Primordial(状态累积大数字)
入口:Aquatic Friend 状态件。兑现:Jellyfish「邻水生即加速」与 Pufferfish「收到 Haste 即充值」互锁自动机。封顶:Shipwreck(全池唯一 Diamond)全体 Aquatic +1 Multicast;Slumbering Primordial 状态→充能+成长三职齐备。

3.3 暴击轴(多件叠率)

Custom Scope(右件 +crit) → Swash Buckle(邻件 +crit) → Wanted Poster(全版 crit + XP) → Cutlass(crit 双倍伤害)
设计特征:Crit 是常驻 buff 件 + 武器暴击标签的堆叠游戏,从 Bronze 到 Gold 全档。单武器极值:Sniper Rifle(100 + 只武器 3-10 倍)与 Cutlass 双倍暴击——「单武器过滤」是 Vanessa 高倍率句式的标准出法。

3.4 慢控轴(防御输出一体)

Tripwire / Iceberg(敌用品即慢/冻) → Bolas / Fishing Net(大范围慢) → Jitte / Blowgun(慢件带伤)
密度:Slow/Freeze 件高——PvP 语境下「对方节奏惩罚」,直接类比 OneDeck 敌方诅咒。

3.5 经济 / 车辆辅助轴(弱轴)

经济件:Cove / Ambergris / Lockbox / Orange Julian——4 件,全池最薄,支线补充。车辆(7 件):Flagship / Submarine / Submersible / Tortuga / Rowboat / Seashadow / Shipwreck,与 Captain's Quarters 构成「大件 buff 流」,后期成型。

层设计职责代表件tier 观察

6.2 OneDeck 落点(初筛,正式建议在综合文档)

Bazaar 观察OneDeck 可借鉴不可搬
弹药供给—消费链路「供给件→消费件」有明确接口词汇,构筑深度来自链长——OneDeck 的「埋→墓→复活」链已是同类,可参考供给量可视设计秒表式实时冷却不能映射到轮次制
事件源三职(Slumbering Primordial)OneDeck 的 xN 段数 × 力量公式已是同类——对照台面—
「相邻/右侧」位形语法OneDeck 是类型/阵营触发,位形语法不建议引入除非做专门位形玩法
敌用品响应件(PvP 惩罚)等价 OneDeck 敌方诅咒/慢件——已有PvP 秒表语境的「节奏破坏」更直接
升级=节奏化OneDeck 无等级制——保留,不做升级不能搬(卡与武器体系不同)

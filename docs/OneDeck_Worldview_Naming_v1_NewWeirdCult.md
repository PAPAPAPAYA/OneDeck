## §0 世界观总纲

### 一句话

> 深夜的都市，教团盘踞于地下。你是一教之主——牌库即你的班底：被你蛊惑的**信徒**、你豢养的**怪异**、你施下的**诅咒**。战斗是两任教主的怪异互噬。信徒是耗材：献祭信徒，怪异得以增强；蛰伏的怪异在条件满足时**活化**，降临于现世。胜者吞并败者的怪异。

### 三支柱

| 支柱 | 内容 | 落到哪 |
|---|---|---|
| 新怪谈 | 异常现象/异常个体，临床而冷静的语感（预案、档案、装置、永动机） | 应急预案、禁区学者、永动机、慢性侵蚀、圣器库 |
| 都市怪谈 | 日常中的恐怖（枕边低语、梦游、棺材匠、乱葬坑、飞蛾人、小绿人） | 已保留的怪谈名 + 大量旧名直接成立 |
| 邪教 | 仪式与代价（献祭、血誓、殉道、皈依、洗脑、密议、教旗） | 机制动词重命名（献祭/请出/招募/牺牲/加深） |

### 命名原则（5 条）

1. **机制关键词统一走新词**：降临 / 献祭 / 请出 / 封存 / 蛰伏 / 活化 / 招募 / 牺牲 / 加深 / 破绽 / 遗言 / 升格。
2. **已符合世界观的卡名一律保留**（约 91 张）：飞蛾人、替死鬼、守夜人、殉道者、乱葬坑、招魂、愚者、献祭仪式……保留名单见 PART 2。
3. **军事/科幻/通用奇幻词 → 邪教/怪谈词**：军火库→圣器库、机器人→人偶、哥布林→小绿人、曼哈顿博士（IP 引用）→禁区学者、永恒引擎→永动机。
4. **通用数值词保留**：攻击、攻击力、攻击 ×N、攻击 +N 次 不动（全卡池最高频词，且与数值的通用性冲突；可选升级为「袭击 / 侵蚀力」，见 §3 待定）。
5. **卡名允许文学性例外**：关键词用「蛰伏」，但卡名可保留「眠」字（尸眠、冬眠、春眠、亘古沉眠者、安眠曲）——机制词一致比卡名词根一致更重要。

### 关键映射速览

| 旧 | 新 | 旧 | 新 |
|---|---|---|---|
| 次元裂缝（token） | **信徒** | 揭晓 | **降临** |
| 沉睡 / 唤醒 | **蛰伏 / 活化** | 埋葬 | **献祭** |
| 复活（旧概念） | 并入**活化** | 置顶 | **请出** |
| 攻击者（tag） | **怪异** | 生成 | **招募** |
| 负面 / 诅咒（tag） | 统一 **诅咒** | 去除（信徒） | **牺牲** |
| 增强（诅咒） | **加深** | 亡语 | **遗言** |
| 易伤 | **破绽** | 延迟 | **封存** |
| 形态升级 | **升格** | Start Card | **教主**（待定） |

> 说明「复活 → 活化」：最终卡池中已无独立「复活」关键词（旧概念在 2026-08-18 讨论中已拆入置顶调度 + 沉睡引擎）。活化一词同时承接两处：① 唤醒蛰伏的怪异；② 招魂/轮回/还魂这类「从墓地请回」的复活意象。

### 1.5 卡面用语示范（新词汇落地的样子）

- **伪神**（原全能人，R）：攻击；攻击力 = 墓地友方卡数 + 友方[信徒]数 + 敌方[诅咒]攻击力总和（常态结算）；若攻击力 ≥ 15：攻击 ×2；降临：招募 1 [信徒]；加深 1 张敌方[诅咒]
- **噬祭兽**（原次元兽，R）：牺牲 1 张[信徒]：攻击
- **司祭**（原裂缝召唤师，U）：牺牲 1 张友方[信徒]：请出 2 张友方[怪异]
- **洗脑师**（原裂隙窃贼，U）：招募 1 [信徒]；萦绕：每当友方[信徒]被牺牲：招募 1 [信徒]
- **惊蛰**（原苏醒之雷，R）：萦绕：每当友方[蛰伏]被活化：其攻击 1 次（攻击力 = 其自身攻击力）
- **大觉醒**（保留，R）：活化所有友方[蛰伏]；各获得 1 攻击力
- **庄重献祭**（原不愚蠢的埋葬，R）：降临：献祭 2 张友方[遗言]/[萦绕]
- **战鬼**（原战争英雄，R）：攻击力 = 友方[怪异]总攻击力（常态结算）；攻击；若总攻击力 ≥ 8：获得 3 攻击力
- **血誓**（原战争之誓，U）：给予 1 张友方[怪异] +2 攻击力；攻击
- **圣迹**（原次元龙，U）：招募 1 [信徒]；被请出：招募 1 [信徒]
- **应急预案**（原快速响应协议，U）：萦绕：每 4 张敌方卡降临：请出 1 张友方卡
- **还魂炉**（原推进器，R）：萦绕：每当友方[怪异]被献祭：请出 2 张友方[怪异]；降临：献祭 1 张友方[遗言]

## PART 3 · 批判与待定

### 3.1 需要拍板的清单

1. **Start Card → 教主（待定）**：fiction 收益最大的一步（牌库最底 = 教主最后降临，王座区 = 教主座前），但要动引擎文档（AGENTS.md / GameRules.md 均用 Start Card）。建议：若采纳，分两步——先文案层，后文档层。
2. **疲劳 → 疯狂、商店 → 黑市（可选）**：纯 flavor 升级，不影响机制语义；不采纳也不影响整体。
3. **攻击/攻击力 是否升级为 袭击/侵蚀力（不建议）**：攻击力是全卡池最高频数值词（149 张卡里约 60 张带攻击文本），改名收益低、成本高；「侵蚀力」建议留作未来第二条数值轴的储备，不要现在占用。
4. **哥布林 → 小绿人（口味取舍）**：哥布林是卡池最后残存的纯奇幻种族；小绿人是正统 UFO 都市怪谈。若担心喜剧感过重，可保留哥布林。
5. **铁匠 → 铸像师（口味取舍）**：铸像师更强绑定邪教（铸造怪异偶像）；铁匠则更「日常恐怖」。均可。
6. **拔苗助长 / 不愚蠢的埋葬（幽默名）**：前者保留（成语画面感强）；后者建议改（「不愚蠢的埋葬」的梗在中文语境下读感偏轻，仪式感不够），备选「体面献祭 / 庄重献祭」。
7. **噬咒家族（咒食 → 噬咒）**：「咒食」是旧案生造词，读感卡顿；「噬咒」更顺且保留"以诅咒为食"设定。若不想动 4 张卡名，保留亦可。

### 3.2 世界观裂缝（已自查，确认通顺）

- **献祭敌方卡**：敌方卡 = 敌教的信徒/怪异。献祭敌方 = 劫掠敌教祭品喂给己方怪异，与人间大炮等「墓地友方卡数」类文本不冲突（各看各的墓地）。
- **[怪异] tag 的边界**：无攻击的效果卡（慢性侵蚀、应急预案、布道所、阈限之门）不属于[怪异]——它们的身份是「异常现象 / 预案 / 场所 / 仪式」。建议在卡面 tag 体系里保留[通用]容纳它们，避免"怪异"称谓吞掉半个卡池。
- **蛰伏免疫献祭**：蛰伏卡不在牌库 → 天然免疫献祭/请出。fiction 上自洽：不在现世的怪异无法被献祭。
- **信徒的呈现**：信徒是"人"，与怪异同卡面语言。美术需要区隔（人形剪影/苍白面孔 vs 怪物轮廓）；信徒被献祭后进墓地，与遗言/骷髅/尸潮等亡灵卡天然打通——这是新世界观送的联动，值得在美术规范里点明。
- **复活 → 活化**：最终卡池已无独立「复活」关键词，活化同时承接「唤醒蛰伏」与「招魂/轮回/还魂的复活意象」，无双义冲突。

### 3.3 实施范围

- 本档不动 `cardTypeID`（存档、统计、CombatPerCardStatsTracker 均依赖它），只改 `displayName` 与卡面文案、tag 体系名。
- 改名落地后需同步：① 预制体 `CardScript.displayName`（脚本化批量改）；② Notion 卡库 `name` 列与 `tag` 选项（multi_select）；③ `docs/OneDeck_Final_CardPool_Design.html` 卡表（若保留该档）。
- 卡面文案中的机制词（降临/献祭/请出/蛰伏/活化/招募/牺牲/加深/破绽/遗言）随预制体批量替换，规则如 §1.2。

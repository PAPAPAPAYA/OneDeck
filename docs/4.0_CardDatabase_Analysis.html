0. TL;DR

  • 库已进入词条化阶段: 99 行中 90 行已配 tag、41 行已填 ATK (均值 ≈1.5); 被动关键词正式化 (19 张, 文案加「被动:」前缀); 3 张重复/冗余已删 (C09 C67 C78), 新增 3 张 (C100 交换 / C101 敌诅咒揭晓复活自身 / C102 墓地生物光环)。
  • 4.0 = 墓地中心化重做。墓地确认为 start card 后的区域: 揭晓后进墓地 (回响除外) → 洗牌回收 (被动除外) → 复活/苏醒构成新资源经济。与现行「揭晓后放回卡组底」是流程级冲突。
  • 机制分布: 复活 33 / 埋葬 24 / 诅咒 22 / 信徒 21 / 被动 19 / 遗言 14。复活是第一大机制 (1/3 卡池) 却不在 9 个 tag 选项里 —— 未挂 tag 的 9 张里 7 张是复活卡, 直接印证缺口。
  • 代码现状比预期好: 攻击力属性重做已落地 (CardScript.printedAttack / attackGrowth / extraAttackTimes / GetAttack() / AttackEffect / AttackResolverSource + onMeGainedAttack 系列事件), 且 AttackResolverSource 已在统计「start card 之后的卡」—— 墓地区域的代码语义部分现成。新增缺口集中在墓地层 (复活/苏醒/被动豁免/回响/回合结束), 见 §7。
  • 数值框架已浮现 (从 41 张已填 ATK 归纳): 效果载体 ATK 0-1 · 基准攻击 2 · 多段压缩 ATK 到 1 (C40 x2@1 / C91 x4@1) · 代价补偿 +2 (C13 埋1友方@4)。v1 的白板多段离群点已被数值兜底。
  • 风险重心从白板数值转移到常驻被动引擎: 19 张被动全部无揭晓位成本、永久 uptime —— 被动池需要独立的「强度税」定价规则 (§5.3)。结构性风险仍是: 苏醒复活链 (C52+C33)、被强化自复活 (C10+C39)、遗言复制指数 (C63+C49)、信徒自增殖 (C27); 注意 C33/C49/C27 均已被动化, 风险等级上调 (§6)。
  • tag 语义漂移需裁定: 「被强化」被挂在多张无被强化文案的卡上 (C40 C48 C60 C91 等 12 张) —— 若新语义 = 「受益于一图流强化的卡」需写明; 另有疑误标 (C02/C36 挂信徒、C56 挂苏醒)。见 §8-Q9。

4. 流派支柱分析

4.1 复活/苏醒 —— 4.0 第一支柱 (复活 33 + 苏醒 6)
  • 复活友方定向族: 信徒 (C04)、生物 (C83)、非生物 (C21)、rare (C72)、normal x2 (C79)、uncommon x2 (C96)、攻击次数最多 (C43)、强化 (C31?)、遗言联动 (C62 延迟复活)。墓地选卡维度极细 (类型/稀有度/段数/状态), 构成 4.0 的「打捞工具箱」。v2: C21 C31 C43 补了「攻击;」前缀, 复活卡开始携带基础攻击。
  • 复活敌方族 (8 张): 复活敌方攻击最高 x5 (C11 C32 C48 C88 C94) = 资敌代价换大收益; 复活敌方诅咒 x3 (C45 C55 C59) = 进攻行为 —— 诅咒是其拥有者的负债, 塞回敌方卡组顶 = 敌方多自伤一次 + 占敌方揭晓位, 对应 V4 E4 的「诅咒揭晓次数」乘区。
  • 复活自身 (3 张): C10 (被强化触发) C50 (友方遗言被埋葬触发) C101 (敌方诅咒揭晓触发, 新) —— 三张都是「事件驱动自复活」, 分别挂在强化/遗言/诅咒三条轴上。
  • 苏醒是被复活时的兑现口: 生成信徒 (C01)、自强化 (C22)、再复活 (C52)、埋葬敌方 (C54)、触发遗言 (C33 苏醒-遗言桥, 已被动化 = 常驻生效)。苏醒把「复活」从纯位移升级为触发器, 是复活流的收益乘区。
  • 数值引擎: C02 攻击力=本回合复活数 (finisher, ATK 0); C36 每复活1友方增强诅咒1 (复活-诅咒桥, 已被动化)。
4.2 信徒 —— 资源货币 (21)
  • 生产 (14): 攻击挂钩 (C01 C03 C08 C77 C97)、事件挂钩 (C27 每次友方攻击 / C44 每次卡片被埋葬 / C73 埋葬全友方, 均已被动化)、回合开始 (C56)、直给 (C26 C28 C30 C88)。
  • 消耗/转化 (6+): 放逐1→攻击x3 (C60)、放逐全部→每1强化1友方 (C25)、攻击力=本回合放逐信徒数 (C92, v2 限定本回合 = 削弱)、复活信徒 (C04)、信徒揭晓磨牌 (C15)、信徒效果改写 (C07 相邻诅咒版 / C76 复活敌诅咒版)。
  • 与 3.0 次元裂缝相比, 4.0 信徒新增三个维度: 可被复活、揭晓可被监听、效果可被改写 —— 从「弹药」升级为「生物资源」。信徒自身能否攻击仍是全池最关键的未定点 (见 §8-Q1), 直接决定 C27 是否指数失控 (见 §6-4)。
4.3 诅咒 (22)
  • 大小乘区: 直给增强 C05 (条件系数) C74 (+6) C84 (+4, v2 补攻击0) C89 (+2); C95 敌方诅咒攻击力=墓地友方数 (被动持续刷新, 构建级)。
  • 次数乘区: C16 被动:敌方诅咒攻击次数+1 —— v2 移除「放逐自身」代价, 从一次性工具变成常驻倍率, 诅咒流大幅加强 (见 §5.3); C51 每次攻击增强1。
  • 揭晓次数乘区: 复活敌方诅咒 (C45 C55 C59) + 信徒改写 (C76) —— 把诅咒反复塞回敌方卡组顶。
  • 镜像: C85 自身攻击力=敌方诅咒攻击力 (ATK 0 占位, 动态接管)。
  • 新桥: C101 敌方诅咒揭晓时:复活自身;攻击 —— 诅咒揭晓次数乘区的受益方, 诅咒环境越浓越强 (见 §6-5)。
  • 替换: C20 友方攻击不再造成伤害、转为增强等量敌方诅咒 (已被动化) —— 伤害永不落地换诅咒滚雪球, 体验极端化 (见 §6-8)。
4.4 遗言 (14)
  • 3.0 的遗言 = 被埋葬触发一次; 4.0 把遗言变成可操纵资源: 触发两次 (C49, 已被动化 = 常驻双倍, 见 §6-3)、被苏醒触发 (C33)、授予他人 (C71 C93)、复活自身 (C50 C71 授予版)、复制自身 (C63)、延迟复活 (C62)。
  • 配套定向埋葬工具: 埋葬遗言友方 (C69)、埋葬最低攻友方并强化 (C39)、埋葬全友方 (C73)。
  • 注意与「埋葬友方代价族」(12 张) 的协同: 代价越重, 遗言收益越大, 自埋流自成一派。
4.5 被动 —— 从候选到正式关键词 (19)
  • v1 的 17 张「被动候选」中 15 张已加「被动:」前缀; C07 C16 C49 三张新加入 (含效果改写); C98 移出 (改写为攻击卡), C50 未标记 (待裁定, 见 §8-Q4)。新增 C102 墓地生物光环。合计 19 张。
  • 被动 = 3.0 萦绕的永久化: uptime 从约 0.5 提到约 1.0 且永不占用揭晓位 → 引擎卡强度档整体上移约 2 倍。这不是单卡问题而是定价框架问题: 19 张常驻引擎全都需要独立的强度税 (低数值/条件门槛/自代价), 见 §5.3。
  • 结构性待定: 被动永不揭晓 → 被动卡上的「攻击」动作永不执行; C50 (复活自身;攻击) 未标被动但有持续触发文案 —— 「非被动卡在墓地能否触发」是规则地基问题 (§8-Q4)。
4.6 次数/多段 + 动态攻击力
  • 段数卡: x2 八张、x3 三张 (C48 C60 C82)、x4 一张 (C91); 次数授予五张 (C16 C23 C35 C47 C90) —— V4 的第一乘区授予在 4.0 保留且扩展。
  • 动态攻击力七张: 本回合复活数 (C02)、敌方最高攻复制 (C11)、墓地友方数 (C18)、友方最高攻 (C61)、敌方诅咒攻 (C85)、本回合放逐信徒数 (C92)、敌方诅咒攻=墓地友方数 (C95); 翻倍一张 (C75)。

5. 强度粗评 (僵尸基准框架, ATK 已部分回填)

6. 循环与自洽风险

现有防线: 链系统 (同卡同效果实例一链一次 + 深度 99) + 疲劳 (揭晓总数) + V4 已声明 combat 生成不受 12 卡位限制。v2 关键变化: 多张引擎卡已被动化 = 常驻生效, v1 依赖「萦绕 uptime 0.5」的风险折扣全部取消。以下按风险排序:

风险 #1苏醒复活链 (C52 + C33) — 已被动化, 上调
C52 复活 A → A 苏醒再复活 B → B 是复活卡则续链。同链不同实例可拉空墓地; C33 (苏醒触发遗言) v2 已被动化 = 常驻桥上, 每环白嫖一次遗言; 配 C02 (攻=复活数) 伤害爆炸。非真无限 (链实例守卫), 但单链深度 = 墓地复活卡数。建议: 每回合复活计数软上限, 或苏醒触发加链外冷却。
风险 #2被强化自复活滚雪球 (C10 + C39 + C12/C86)
C39 埋葬最低攻友方并强化它 → 若它是 C10「被强化:复活自身」则回顶 → 揭晓攻击 → 再被埋。每循环 C10 永久 +1 (若带 C12/C86 自强化) + 一次攻击。跨回合无上限成长, 靠疲劳兜底, 需要监控。
风险 #3遗言复制指数化 (C63 + C49) — 已被动化, 上调
C63 遗言复制自身; C49 (被动:本回合埋葬5友方:遗言触发两次) 常驻后, 满足条件的每回合遗言都双倍 → 1→2→4 指数 (史莱姆是线性, 这是指数版)。建议: 沿用增殖的厄运裁定: 复制体不再被复制, 或改线性。
风险 #4信徒自增殖 (C27, 条件性, 已被动化)
「被动:每次友方攻击, 生成1信徒」常驻。若信徒自身能攻击 → 攻击生信徒、信徒攻击再生信徒, 同链不同实例滚全卡组, combat 生成又无上限。裁定需求: 信徒不能攻击 / 信徒不进揭晓流 / 信徒生成不算攻击事件源。待 §8-Q1。
风险 #5诅咒揭晓自复活锁 (C101 + C55/C59/C76) — 新增
复活敌方诅咒 → 其揭晓 → C101 复活自身+攻击 → 下回合再复活敌诅咒。每轮一次敌诅咒揭晓 = C101 每轮白嫖攻击+回顶; C55 回响1 让工具卡永不消耗。非真无限 (每轮一次), 但零成本自维持。建议: C101 加「每回合限一次」或复活后需重新进墓地的条件。
风险 #6遗言自复活永动 (C50 + C49)
友方遗言被埋葬 → C50 复活自身回顶 → 再揭晓攻击 → 再被埋 → 再回顶。每循环白嫖一次攻击; C49 常驻双倍。需「同名卡每回合限一次」类裁定。C50 未标被动, 其触发区域也需裁定 (§8-Q4)。
风险 #7资敌复活的定价 (C11 C32 C48 C88 C94)
复活敌方攻击最高 = 敌方下回合输出回升, 是负价值; 若敌方墓地无卡或全是低攻卡则代价蒸发 → 需要「敌方墓地为空时」的落空文案。
风险 #8替换效果极端化 (C20, 已被动化)
友方攻击全转诅咒增强 → 伤害永不落地, 敌方无诅咒反制则慢性死亡, 有反制则我方输出归零。全或无的卡, 需要上限 (如每回合转换上限)。

3. 构筑轴识别

3.1 Rage→Enrage 双态引擎轴(身份轴)

Rage 获取(用武器/暴击/治疗/慢/烧/敌用件 → +Rage) → 触发 Enrage(阈值) → 狂暴兑现(伤害/冷却缩减/最大生命/Multicast) → 停怒第二波(Firefly Lantern / Frog Hollow / Tent)
入口:Rage 获取件(Eagle Sigil 暴击→Rage、Tranquil Sigil 治疗→Rage、Enervating Sigil 慢→Rage、Vengeful Sigil 敌用→Rage、Bear Mask 首次使用→30 Rage)。兑现:Enrage 触发件(Assault Sigil 狂暴→10% 最大生命伤害、Battle Axe 狂暴+60 伤、Great Eagle 狂暴→3 件起飞)。封顶:Tree Club(1000 伤,狂暴期间自充)、Outlands Terror(狂暴期间吸生+半冷却+双倍 Rage 获取)、Wild Bear(狂暴+20% 最大生命)。
停怒态:Firefly Lantern(停怒→使用)、Frog Hollow(停怒→全体 Haste)、Tent(停怒→20% 最大生命盾)——「愤怒循环」的第二波,是 Karnok 独有节奏。

3.2 皮甲/防御轴(身份标签)

Apparel 26 件 → 最大生命(Forest Cloak +20% 最大生命、狂暴期间半伤)→ 防护(Masks 首次使用→Rage + 狂暴 Max Health)
密度:Apparel 26(22%)——皮甲是 Karnok 的「耐久」标签,几乎都挂 Rage/Enrage 之一(如 Bear Mask 首次使用+30 Rage、狂暴+10% 最大生命)。

3.3 野兽随从轴

Friend 22 件(Wolf / Wild Bear / Honey Badger / Great Eagle / Outlands Terror)→ 狂暴期间友军强化(Wolf 狂暴→Haste 友军 / Karst 用友军→Rage+盾)
特征:野兽随从与 Rage 深度绑定——友军既是 Rage 来源(Karst)又是狂暴兑现目标(Wolf)。

3.4 捕猎/慢控轴(次轴)

特征:Slow 25 + Trap 4 —— 猎人主题的「布陷阱 + 减速猎物」控制(Log Trap 首次敌用→500 伤 + 全慢),Trap 在狂暴后可重复触发。

1. 总体架构

商店是一个纯世界空间(world-space)单页:货架、卡组带、升级行、顶栏、面板全部是 SpriteRenderer + 世界 TextMeshPro + BoxCollider2D 物理点击,没有任何 uGUI 交互(战斗画布在商店阶段隐藏,仅作过渡共享元素)。 2026-09-21 起顶栏也是页面内容:Build 时定位一次,滚轮下滚随整页一起离屏,不跟随相机。

页面纵向结构(自上而下,世界坐标,正交相机静止位 y=0):

y ≈ +5.6   顶栏 Shop Chrome (页面内容, 非相机锚定)
           row0: [离开商店] [头像+用户名 | HP药丸] [$钱包] ......... [❚❚]
           row1: ✦ / ✦✦ / ✦✦✦ 稀有度概率 (左对齐 HUD 列)
           row2: 🜲 胜数 | ♥ 心数 | +$/ROUND 收入
y ≈ +4.3   商店面板 header 行 (「商店」标题 + 重掷按钮)
y = +1.5   货架 (shopItemPos 起, 3列网格, 4+张自动换行并把卡组带下推)
y = -3.4   卡组带 (playerDeckPos 起): 「卡组」header + 03/05 计数器
           占格卡 + 凹陷空卡位 (每 deckSize 格一个, 永不被消耗)
卡组带下   升级行 (utility 被动, 不占卡位): 「商店升级」header
y ≤ 滚动   滚轮下限 = 最低内容行 - padding

战斗页位于商店页正上方一个屏高(PhaseTransitionDriver 把 7 个战斗世界标记 +pageH),由「离开商店」按钮触发相机纵向travel过渡。

行为规则

  • 一次性定位:Build 时写根位置(视口顶部、滚动 0 的等价值)并捕获 BandBottomWorldY(= 相机 y + orthoSize − 2.6);之后不再跟随相机,随滚轮离屏。
  • 货架契约:货架最顶卡(含价格按钮余量 2.5×scale)不得越过 BandBottomWorldY,每次货架重建由 CheckShelfClearance 断言(越线仅 [ShopChrome] 警告,不拦截)。
  • 显示/隐藏:进店 EnterShop 显示、离店隐藏;过渡中(PhaseTransitionDriver.IsTransitioning)不显示,落地后再显示(Result→Shop 落地回调)。
  • 刷新:买/卖/重掷/显示时 RefreshIfActive,全部字段差分守护,文本变了才重建 mesh。
  • 离开商店按钮是唯一的 canonical 商店→战斗触发:优先走 PhaseTransitionDriver.RequestShopToCombat,驱动不可用时回退硬切(ExitingShopPhase + EnteringCombatPhase)。
  • 滚下去看不到顶栏是有意的(用户裁定):滚回顶部或按 Space 离开。

6. 世界镜像 ShopPageHud

settled shop 中 canvas 头像/HP 隐藏后,由世界副本顶上(挂 chrome 根下,随页面滚动)。镜像规则:

  • 镜像而非重绘:遍历 canvas 源(玩家 CombatIconPresenter.playerIcon 层级、玩家侧 HPNumericDisplayHorizontal.displayRoot 层级)逐子物体拷 sprite/颜色/字体,px → 世界经 CanvasPxToWorld 校准;滚动 0 处与 canvas 原件像素级一致。
  • HP 数字合并为单个世界 TMP「hp/hpMax」(无里程表条):商店恒满血,但买/卖 HP utility 会移动 hpMax,数值变化播 ~0.3s 整数 count-up/down tween(CountUpSeconds = 0.3)。
  • 字号换算 TmpWorldUnitsPerEm = 0.1;层叠 z 步进 0.01(canvas 后→前 = z 大→小)。
  • 9-slice 边框保真:SlicedWorldSize / SlicedWorldScale(VISUAL-FIX 2026-09-21,child localScale + border 比例)。
  • canvas.scaleFactor 首渲染时序陷阱用 ComputeCanvasScaleFactor(按 CanvasScaler 公式重算)规避。
  • 用户名轮询 PlayerIdentity.Username,空 → 「???」,差分刷新;无碰撞体,不可交互。

10. 输入管线与快捷键

  • 单一物理管线:所有商店交互(按钮、卡体点击放大/还原)走 OnMouse 物理,ShopInputGate 引用计数统一门禁(重掷期间 Block;过渡期间 Block/由驱动接管)。没有 uGUI 输入。
  • 键盘:Space = 离开商店(PhaseManager,滚动到一半也能离开)。⚠ ShopManager.Update 里的 S(买卖切换)、R(重掷)、1-6(数字键买/卖)全部已注释停用。
  • ⚠ 场景 phaseInfo 文案(「Press SPACE / R / NUMBER KEY / S …」)是遗留物,与实际键盘支持不符,仅存于数据未展示。

进店结算流程 (EnterShop 顺序)

  1. RunRecorder.OnShopEnter(Async-PvP 快照,发放前)→ 清访问计数器
  2. RefreshUtilityBonus(从当前卡组重算全部 utility 贡献,无累积监听)
  3. ApplyBaselineGrowth:deckSize = valueOg + 每场成长 + 扩容购买次数,钳 [1, 12];补空卡位;hpMax 同公式重算且 hp = hpMax(商店恒满血不变式)
  4. 钱包 += GetCurrentPayday() = payCheck + 收入成长 + utility income 加成
  5. GenerateShopItems(§12)+ ApplyBoardDiscount(半价掷签)
  6. 显示 chrome / panels,记录 ShopStatsManager 访问

卖卡 = GetCardPrice / 2(整数除);非物理卡不可卖;每次买/卖后重算 utility bonus + hpMax 满血,并 pulse 对应 deck 实例(1.2× OutBack 0.12s)。

12. 货架生成管线 (ShopBoardPipeline)

纯静态、注入 Rng.Channel(Shop)(确定性随机)。当前模式 = 混池(mixedPool):

步骤规则(当前生效路径)
1. 池分类utilityKind ≠ None/ OddsUtility 的卡 + 扩容卡 → utility 池;OddsUtility 双池;其余 → 战斗池。已拥有的 utility 类型从双池剔除(own-once);到上限时扩容卡全链剔除
2. 通用槽槽位 = shopItemAmount(3) + extraShopOptions;战斗/utility 卡同一混合池(引用去重防 OddsUtility 权重翻倍)按权重 roll:weight = 会话表(rarity) × shopRollWeightMultiplier × utility 稀有度乘子
3. 波过滤仅战斗波生效:生物波命中 → 只生物;现象波(命中且生物波 miss)→ 只 CardType.None;过滤后为空回退全池(波永不清空货架)
4. 机会加槽utility bonus extraBoardSlots 命中 extraBoardSlotsChancePercent(如魇市游摊 13%)→ 本板 +N 槽,独立 per-board 概率,无保底无 pity
5. 保留槽追加在通用槽之后,永不挤占;每板独立 chance roll(默认 25%),firstBoardOnly 只在第 0 板;按 rarity / tag / ODDS 谓词绕过权重均匀抽;混池从合并池抽;utility 板抽空回退普通权重 roll

15. 观察与注意事项

货架净空临界:按当前正交 6.06,货架空位公式算出的行 0 卡顶(含价格按钮余量)= 1.5 + 2.5 × 0.8 = 3.50,而 chrome 带底 = 0 + 6.06 − 2.6 = 3.46 —— 理论上 CheckShelfClearance 每次货架重建都会报 0.04u 越线警告。这正是未落地计划 plans/plan-shop-topbar-heightfit-resize-2026-09-21.md 的课题(相机高度自适应),当前以警告形式存在,不拦截。
phaseInfo 文案过期:S/R/数字键已停用(代码注释),快捷键实际只剩 Space(离开)+ 滚轮 + 物理点击;但 phaseInfo 字符串仍宣传四组快捷键。清理属低风险项,待拍板。
  • 相机正交尺寸 6.06 无代码写入点,纯场景值;Game 视口宽高比大变会破坏顶栏世界常量的对位(ShopTopBarLayout 顶部已注明该 caveat)。
  • sessionUtilityBoardChances 表在混池模式下休眠;若未来切回 split 模式,注意场景表是 20/15/10 递减而非代码默认的 10/15/20 递增。
  • EditMode 覆盖:ShopPageHudTests 像素金证(B1/B2)、ShopSectionPanels 静态助手(FormatSlotCount / ComputeContentBounds / CountUsedSlots)、PhaseFlightPlanner 布局计算。
  • 统计埋点:ShopStatsManager(进店/出现/购买/重掷,boardType 维度)+ RunRecorder Async-PvP 日志(goldEnter/goldAfterPayday 等),离店 Flush。

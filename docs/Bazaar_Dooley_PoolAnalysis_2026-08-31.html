3. 构筑轴识别

3.1 核心→链引擎轴(身份轴)

Core(Combat / The Core / Weaponized Core)「使用左侧件→充能自身/右侧」 → 物品链(任意件在左触发) → 充能加速(Critical Core 暴击自充 / Focused Core 右件充能) → 引擎闭环
入口:Core 件本身(12 件),以及任何「左侧触发」的物品。兑现:核心输出(Combat Core 50 伤+50 盾、The Core 充能右件)。封顶:Diamond 引擎(Robotic Factory 全体 Friend +1 Multicast、Oblivion Core 摧毁敌人+自充)。
桥:C.O.R.A(敌毒→伤 / 用右件→毒)、Primal Core(恐龙/遗物充能)、Focused Core(右件充能+提速)。「核心→右侧链」是 Dooley 版自动机链——比 StS2 任何角色更接近 OneDeck 的事件自动机。

3.2 友军/恐龙轴

Companion Core(友军充能) → Friend 武器(Bellelista / Clawrence / Dooltron) → Dinosaur 随从(Momma-Saur / Tanky Anky / Terry-Dactyl) → Robotic Factory(全体 +1 Multicast)
密度:Friend 39(27%)+ Dinosaur 9(6%)。Friend 件多是「战斗型友军」(武器+Friend 19 件),随从流可独立成军。

3.3 射线轴(小轴)

Alpha Ray(用 Core/Ray→武器+伤) → Beta Ray(用 Core/另一 Ray→自充) → Gamma/Epsilon/Omega Ray
特征:5 件 Ray 互充互养——「用任一 Core 或 Ray 触发另一 Ray」的小型自动机族,配合核心轴极佳。

3.4 状态/战斗轴(次轴)

特征:Burn 31 + Poison 14 + Freeze 15 + Shield 31 —— Dooley 有大量状态武器(Plasma Rifle / Flamethrower / C.O.R.A)与护盾,是「技术向战斗」。

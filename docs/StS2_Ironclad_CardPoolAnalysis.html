0. 角色骨架

  • 属性:80 HP(全角色最高)、3 能量、起始遗物 Burning Blood(每场战斗后回复 6 HP)。
  • 起始牌组(10 张):Strike ×5、Defend ×4、Bash ×1 —— 唯一的职业卡是 Bash(2 费 8 伤 + 2 易伤),把「易伤」作为起手教学。
  • 身份关键词:Exhaust(27 张) 全游最密集 —— 消耗堆不只是机制,而是「计数资源」与「二次使用区」;力量 与 易伤 是两条经典成长轴;新补丁强化了 自伤(HP 即资源) —— 放血换能量 / 力量 / 伤害是 StS2 铁甲的招牌句式。
  • 新机制:Fatal(击杀非随从敌人时触发 —— Feed 击杀 +3 最大 HP)、Plating(回合结束获得格挡,回合开始 -1 的衰减甲 —— Stone Armor)、Giant Rock(1 费 16 伤 token,由 Primal Force 把整手攻击转化而来)、Strike 卡族(Perfected Strike 按 Strike 卡计数、Hellraiser 自动打出抽到的 Strike)。
资源轴速览:力量 = 成长轴(每段伤害 +1);消耗堆 = 计数/回收轴(Ashen Strike / Pact's End / Midnight / Howl from Beyond);HP = 可透支资源(Offering / Bloodletting / Rupture / Inferno);格挡 = 存量轴(Barricade / Body Slam / Juggernaut)。

4. 主线与构筑关键卡

4.1 消耗轴(身份核心)

制造消耗(自耗 / Fiend Fire / Stoke / Second Wind)→ 消耗堆计数(Ashen Strike / Pact's End / Midnight 降费)→ 消耗事件回报(Dark Embrace 抽 / Feel No Pain 防)→ 二次使用(Howl from Beyond)
环节卡作用
消耗源Cinder / True Grit / Havoc / Burning Pact / Second Wind / Fiend Fire / Stoke / Corruption(Ancient)主动消耗手牌/牌堆的卡,把消耗量做出来
计数兑现Ashen Strike ★ / Pact's End ★ / Midnight ★ / Howl from Beyond ★每张 +3 伤;≥3 张全敌 18;12 费 60 伤按消耗数归零;回合末从消耗堆再打
事件回报Dark Embrace ★ / Feel No Pain ★ / Drum of Battle / Evil Eye / Second Wind每次消耗:抽 1 / +3 防 / +1 能量 / 8+8 防 / 5 防/张
封顶Fiend Fire ★ / Corruption整手变伤害(7/张);技能全 0 费但消耗 —— 消耗流闭环终点
构筑关键卡:Fiend Fire、Pact's End、Ashen Strike、Midnight、Dark Embrace、Feel No Pain、Howl from Beyond、Corruption
引擎形态:Dark Embrace(消耗抽 1)+ 大量消耗源 → Ashen Strike / Pact's End 每回合白涨 → Howl from Beyond 回合末免费再打 → Midnight 最终归零。消耗轴是「垃圾经济学」的正统 —— 消耗越多的牌组,越强。

4.2 力量轴

堆力量(Inflame / Demon Form / Brand / Rupture / Setup Strike)→ 多段攻击兑现(Whirlwind / Twin Strike / Sword Boomerang / Conflagration)→ 段数×力量乘法滚动
环节卡作用
力量源Inflame ★ / Demon Form ★ / Setup Strike / Brand / Fight Me! / Monologue 系永久 / 每回合 / 临时 / 放血换 / 敌我双给(升满 3)
自伤联动Rupture ★ / Inferno / Tear Asunder掉血 → +1 力;掉血 → 全敌伤害;掉血次数 → 段数 —— 力量与自伤两轴互相喂养
多段兑现Whirlwind ★ / Sword Boomerang / Twin Strike / Conflagration / Stomp把力量乘进每段;Whirlwind 是 X 费群攻
单段大数Bludgeon / Mangle / Rampage ★32 伤 / 20 伤 + 敌 -10 力 / 本场每打出 +5
构筑关键卡:Demon Form、Inflame、Rupture、Whirlwind、Rampage、Twin Strike
引擎形态:首回合 Demon Form / Rupture+放血 → 中盘 Whirlwind / Boomerang 每段吃满力量。力量轴是铁甲的「数值地板」,任何牌组都可挂 1-2 张。

4.3 自伤轴(HP 即资源)

80 HP + 战后回 6 → 放血换资源(Offering / Bloodletting / Hemokinesis / Brand / Blood Wall)→ 掉血事件反哺(Rupture 力 / Inferno 伤 / Spite 段 / Tear Asunder 段)
环节卡作用
放血兑换Offering ★ / Bloodletting / Hemokinesis ★ / Brand / Blood Wall / Breakthrough6 HP→2 能量抽 3;3 HP→1 能量;2 HP→15 伤;1 HP→1 力;2 HP→16 防;1 HP→全敌 9 伤
掉血回报Rupture ★ / Inferno ★ / Spite / Tear Asunder ★ / Crimson Mantle / Pyre掉血 +1 力;掉血全敌伤;本回合掉血双段;本场掉血次数 +1 段/次;每回合 -1 HP 换 7 防;每回合 +1 能量
血线安全Burning Blood(遗物)/ Not Yet / Feed ★ / Colossus战后回 6;奶 10;击杀永久 +3 最大 HP(本场成长);对易伤敌减伤 50%
构筑关键卡:Offering、Hemokinesis、Rupture、Tear Asunder、Inferno、Feed、Not Yet
引擎形态:Offering 起手白赚 2 费 3 牌 → Rupture 把掉血变成永久力量 → Tear Asunder 每回合掉血越打段数越多 → Feed 收尾时把血线重新拉高。自伤轴是「用血买速度」,也是三轴里唯一自带回血闭环的。

4.4 易伤轴

上易伤(Bash / Thunderclap / Tremble / Uppercut)→ 层数放大(Bully +2/层、Dominate 每层 +1 力)→ 事件回报(Vicious 抽牌 / Cruelty +25% 伤)→ 翻倍(Molten Fist)
环节卡作用
上易伤Bash(起始)/ Thunderclap ★ / Tremble / Uppercut / Taunt / Break(Ancient)单/群/高额(3 层)/ 附带虚弱 / 附带格挡 / 5 层
层数兑现Bully ★ / Dominate ★ / Dismantle / Molten Fist ★每层 +2 伤;每层 +1 力;有易伤则两段;易伤翻倍
事件/全局Vicious ★ / Cruelty ★ / Colossus / Mangle施放抽 1;易伤敌 +25% 伤害;对易伤敌减伤;敌 -10 力
构筑关键卡:Thunderclap、Bully、Dominate、Molten Fist、Vicious、Cruelty、Dismantle
引擎形态:Thunderclap 全屏易伤 → Vicious 每回合补牌 → Bully / Dominate 把层数变成数值 → Molten Fist 翻倍滚动。易伤轴是铁甲最便宜的成长轴 —— 单卡即用,不占能力卡槽。

4.5 格挡 / 坦克轴

堆格挡(Impervious / Shrug / Unmovable / Barricade 保留)→ 存量兑现(Body Slam)→ 格挡事件回报(Juggernaut 5 伤 / Rage 反向)→ Plating 衰减甲(Stone Armor)
环节卡作用
格挡源Impervious ★ / Shrug It Off ★ / Blood Wall / Iron Wave / Flame Barrier / Expect a Fight(力量×5)30 一次性 / 8+抽 / 16 放血 / 5+5 攻 / 12+反弹 / 15+力量放大

存量兑现Body Slam ★ / Juggernaut ★ / Rage ★伤害 = 格挡;获得格挡时打 5;攻击时 +3 防 —— 攻防双向互转
构筑关键卡:Barricade、Body Slam、Juggernaut、Impervious、Unmovable、Stone Armor、Rage
引擎形态:Barricade 保留 → 每回合格挡滚雪球 → Body Slam 把格挡打成伤害 → Juggernaut 每跳 5 伤。格挡轴是「防守即进攻」—— 与 Necrobinder 的 Osty 蓄水池同构,但用可保留的格挡而非血条。

环节卡作用

纯直伤Bludgeon(32)、Mangle(20)、Reap 系、Break(Ancient 20+5 易伤)大数字集中在高费/远古
成长型Rampage(每打出 +5)、The Scythe 系、Tear Asunder(掉血段数)、Perfected Strike(Strike 计数)、Ashen Strike(消耗计数)五种不同的存量 → 伤害形态
多段Sword Boomerang、Twin Strike、Whirlwind、Conflagration、Stomp、Unrelenting力量乘区的主要载体
群伤Breakthrough、Thunderclap、Conflagration、Whirlwind、Stomp、Howl from Beyond、Pact's End放血换 AOE 是铁甲特色(Breakthrough 1 HP→9 全敌)
条件型Body Slam(格挡)、Bully(易伤层)、Dismantle(易伤两段)、Spite(掉血双段)、Molten Fist(翻倍)、Feed(Fatal)条件 = 铁甲伤害卡的主体
转化Primal Force → Giant Rock(16 伤)、Fiend Fire(整手 7/张)把资源一次性变现

6.3 一张卡干两件事

  • Pommel Strike:9 伤 + 抽 1(伤害 + 过牌)
  • Headbutt:9 伤 + 弃牌堆置顶(伤害 + 回收)
  • Pillage:6 伤 + 抽到非攻击(伤害 + 过滤)
  • Iron Wave:5 防 + 5 伤;Shrug It Off:8 防 + 抽 1
  • Rage / Juggernaut / Body Slam:攻击↔格挡双向桥
  • Cinder:18 伤 + 消耗 1 张(伤害 + 消耗源)
  • Hemokinesis / Brand:伤害/力量 + 掉血事件(触发 Rupture / Spite)
  • Unrelenting:14 伤 + 下张攻击 0 费(伤害 + 降费)
  • Second Wind:整手非攻击变格挡(防御 + 消耗源)

7. 设计观察

  1. 消耗堆 = 铁甲的「第二牌库」:计数兑现(Ashen Strike / Pact's End / Midnight)与二次使用(Howl from Beyond)让「消耗」从代价变成收益 —— 与 Silent 的弃牌、Defect 的状态卡回收、Regent 的锻造是同一设计母题(垃圾经济学)的四种变体。
  2. HP 是可透支资源:全角色唯一把生命当作费用支付手段的角色(Offering / Bloodletting / Hemokinesis),且用 80 最高血量 + 战后回血 + Fatal 成长(Feed)构建闭环 —— 「用血买速度,用击杀还血」。
  3. 易伤是「三合一」debuff:同时是增伤(50%)、计数器(Bully 层数)、事件源(Vicious 抽牌 / Dominate 力量)—— 一张 debuff 打通三条收益线,这是 StS2 铁甲相对 StS1 的最大设计升级。
  4. 能力卡 Rare 占比全角色最高(37%):大数字与全局引擎都依赖常驻能力(Demon Form / Barricade / Dark Embrace / Corruption),这意味着铁甲的构筑节奏是「先立引擎,再滚动」。
  5. 多段攻击是力量的唯一乘区出口:Sword Boomerang / Whirlwind / Conflagration 把力量乘进每段 —— 力量轴的存在让多段卡天然保值,反之亦然。
对 OneDeck 的参考:① 「负资源(HP)换正资源(能量/力量)」与 Necrobinder 的自我 Doom 同句式,代价类型决定了牌组风险形状;② 一个 debuff 同时充当「状态、计数器、事件源」三职,是提高卡池联动密度的低成本手段;③ 消耗/弃牌/回收三类「垃圾经济学」可以并存于同一卡池的不同角色,形成差异化身份。

0. 角色骨架

  • 属性:75 HP(Ascension 2+ 为 60)、3 能量、起始遗物 Divine Right(每场战斗开始获得 3 星)。
  • 起始牌组(10 张):Strike ×4、Defend ×4、Falling Star(0 费 8 伤 + 虚弱 + 易伤)、Venerate(获得 2 星)—— 两个职业卡直接演示「花现成资源打爆发」与「积累星币」两种节奏。
  • 核心系统 · 星币(Stars):与能量平行的第二货币。回合结束不清零、无上限 —— 是「存得住的钱」。16 张卡围绕星的获得/花费/计数展开;自动机(Genesis / The Sealed Throne / Venerate)提供每回合稳定收入。
  • 核心系统 · Forge(锻造):打出带 Forge 关键词的卡时,王权之刃(Sovereign Blade)被创造(本场首张);此后每次 Forge 永久提高其伤害 —— 单局内一个集中成长的武器。Blade 是 2 费 Retain 攻击卡,伤害可滚到 70-100+。
  • 其他机制:随从转化(BEGONE! / CHARGE!! / GUARDS!!! 把卡变成 0 费随从 token)、创造(随机无色卡入手,4 张相关卡 + 3 张兑现件)、Debris(负面状态塞手)、Plating(衰减甲)、Vigor(下次攻击增伤)。
资源轴速览:星币 = 存款轴(跨回合积累,获得/花费都是事件源);Forge = 单武器成长轴;随从 = 转化战力轴(牌库工程 + 0 费打点);创造 = 随机收益轴(无色卡池)。

7. 设计观察

  1. 双货币 = 全游唯一「可储存经济」:能量是当回合预算,星币是跨回合存款 —— 这让 Regent 的构筑节奏完全不同:其他角色「每回合重新规划」,Regent「先存后花」。自动机(Genesis / Sealed Throne)把存款做成稳定收入后,Black Hole / Radiate 让「得星」自动变成伤害 —— 存款 + 利息的数值结构。
  2. Forge = 集中式成长:与 Claw(全卡池共享成长)、The Scythe(单卡成长)都不同,Forge 是「所有卡共同喂养一张卡」—— 王权之刃是唯一兑现池。这种设计的优点:构筑目标极度清晰(所有锻造卡指向同一终点);缺点:Blade 被移除/未抽到时锻造卡全部贬值(Summon Forth 的存在正是补偿)。
  3. 创造 = 随机收益的「外挂卡库」:把无色卡池做成 Regent 的第四轴,创造事件被 Arsenal / Pillar / Supermassive 三路变现 —— 与 Defect 的白噪声、铁甲的地狱之刃同构,但升级为主线。随机性收益需要事件回报件兜底,这是「创造」设计的必要条件。
  4. 垃圾经济学第四形态:铁甲消耗、静默者弃牌、Defect 状态回收、Regent 随从转化 —— 四个角色用四种方式把「废卡」变成资源。转化是其中最温和的(不损失卡面价值,只是换形态),适合作为新角色(Regent)的入门机制。
  5. 大数字密度全游最高:Devastate 35 / Comet 33(0 费)/ Seven Stars 49 —— 与 Necrobinder 的 Bury 52、铁甲的 Bludgeon 32 同属「大数字美学」,但 Regent 把它做成了主线而非个别卡。
对 OneDeck 的参考:① 跨回合货币(星币)是区别于「当回合费用」的第二个经济维度,自动机收入 + 事件兑现(得星=伤害)是其标准句式;② 集中式成长(所有卡喂一张)与分散式成长(Claw / 卡面成长)的选择决定构筑目标清晰度;③ 双主线互不消耗同一资源(星币轴 + Forge 轴)是「并行构筑」的可行性基础。

0. 角色骨架

  • 属性:70 HP、3 能量、起始遗物 Ring of the Snake(每场战斗开局额外抽 2 张)。
  • 起始牌组(12 张,全角色最大):Strike ×5、Defend ×5、Neutralize(0 费 3 伤 + 虚弱)、Survivor(8 格挡 + 弃 1 张)—— 弃牌动作从第一回合就存在,为 Sly 轴做教学铺垫。
  • 身份关键词:Sly(9 张) —— 从手牌被弃置时自动 0 费打出,是 StS2 静默者的核心新机制;Shiv 与 毒 延续 StS1 双轴;敏捷 与 Retain / 弃牌协同构成运转层。
  • 结构性特征:技能卡占一半(46/91)—— 静默者的攻击密度由「Shiv token」「Sly 免费打」「毒 DoT」三种不占卡位的伤害源补足,本体卡大量承担运转与防守。
资源轴速览:Sly = 免费触发轴(弃牌即 0 费打出);Shiv = token 频率轴(0 费打点);毒 = DoT 存量轴(叠层→触发);弃牌 = 事件源(Reflex / Tactician / Hidden Daggers / Storm of Steel 全部按弃牌结算)。

4. 主线与构筑关键卡

4.1 弃牌 / Sly 轴(身份核心)

弃牌口(Prepared / Dagger Throw / Acrobatics / Calculated Gamble / Storm of Steel)→ 弃置 Sly 卡自动 0 费打出 → 弃牌事件回报(Reflex 抽 2 / Tactician 能量 / Hidden Daggers 刀 / Memento Mori 计数)
环节卡作用
弃牌口Survivor(起始)/ Prepared ★ / Dagger Throw / Acrobatics ★ / Calculated Gamble ★ / Hidden Daggers / Storm of Steel / Shadow Step / Tools of the Trade把弃牌做成常规动作;Calculated Gamble 弃整手抽等量 = 全卡池最强滤牌

构筑关键卡:Master Planner、Calculated Gamble、Reflex、Tactician、Acrobatics、Prepared、Flick-Flack、Memento Mori、Storm of Steel

4.2 毒轴

叠毒(Deadly Poison / Poisoned Stab / Snakebite / Bouncing Flask / Haze / Noxious Fumes)→ 触发端放大(Accelerant +1 次 / Outbreak 立即触发)→ 存量兑现(Mirage 格挡 / Strangle 打牌扣血)
环节卡作用

构筑关键卡:Deadly Poison、Noxious Fumes、Accelerant、Outbreak、Envenom、Mirage、Bubble Bubble
引擎形态:Noxious Fumes 每回合自动叠 → Accelerant 让毒多跳一次 → Outbreak 在 BOSS 战时一次兑现全层 —— 毒是「存得住的伤害」,回合数越长越强。

产刀(Blade Dance / Cloak and Dagger / Leading Strike / Infinite Blades / Up My Sleeve)→ 增幅(Accuracy +4/刀 / Phantom Blades 首刀 +9)→ 形态升级(Fan of Knives 全敌 / Knife Trap 存量兑现)
环节卡作用

  • Malaise:敌 -X 力 -X 虚弱(硬解 + 保护)

7. 设计观察

  1. 弃牌从「代价」变成「收入」:StS1 的弃牌是弃牌流的代价,StS2 的 Sly 让弃牌变成「免费施放通道」—— 这是静默者最大的机制升级。弃牌口(运转)与 Sly 卡(兑现)的两段式结构与 Necrobinder 的「条件制造/条件兑现」完全同构。
  2. 技能卡过半 = 攻击外包:46/91 的技能占比说明静默者的攻击密度全部交给 token(Shiv / Sly 免费打 / 毒),本体卡负责「制造频率」—— 与铁甲的「本体大数字」是相反的解法。
  3. 动作计数 = 成长型伤害的统一句式:Murder(抽)、Memento Mori(弃)、Finisher(攻)、Flechettes(技)、Speedster(抽触发)—— 五张计数卡把「运转动作」本身变成伤害乘区,运转越好的牌组天然越强。
  4. 毒是唯一的「可储存伤害」:其他角色的伤害要么即时要么计数,毒可以跨回合储存并在任意时刻兑现(Outbreak)—— 与 Doom 的「阈值处决」形成对比:毒是渐进兑现,Doom 是阈值即死。
  5. 能力卡全部是「频率放大器」:Envenom / Afterimage / Serpent Form / Speedster / Fan of Knives 都是「每当 X 就 Y」的触发式能力 —— 静默者的能力卡不提供大数字,只放大已有动作。
对 OneDeck 的参考:① 「弃牌/消耗/回收 = 免费资源」的垃圾经济学第三形态(铁甲消耗、静默者弃牌、Defect 状态回收、Regent 转化);② 动作计数伤害(抽/弃/攻/技)是让运转卡池自动获得输出能力的低耦合手段;③ token 攻击(Shiv)是解决「技能卡过半」角色输出密度的标准答案。

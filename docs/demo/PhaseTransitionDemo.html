阶段转换 Demo — 商店 ↔ 战斗 ↔ 结算

世界模型：一整张连续世界，战斗页在上、商店页在下；灰色等高线背景 = 玩家 HP bar display（贯穿两页），战斗页顶部红色带 = 敌方 HP display。转换 = 镜头上下移动，世界本身无缝。

共享元素：玩家头像+HP（商店左上 → 战斗左下）、选项按钮（商店右上 → 战斗右下）、卡组卡（商店卡组行 → 飞入战斗卡堆，弧线中点翻为背面）。敌方 HUD 反向（自上方滑入）。货架卡/价格/筹码是世界内容，随滚动离开。

操作：点【离开，开始新的一天】或在商店页上滑 → 战斗页；战斗页点【结束战斗（演示）】→ result 覆层（不再隐藏玩家头像/HP）；点【回到商店】→ 镜头下移返回。战斗页视觉标准 = CardStackRevealDemo.html（悬浮堆叠），物理/色板 = UIKitDemo.html。

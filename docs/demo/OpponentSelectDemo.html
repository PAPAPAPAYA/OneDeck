选敌页 Demo v4 — 名牌规格 + 红卡 + 两种战斗入场方式

版式（2026-10-08 第二轮）：候选面板 = ShopSectionPanels 同款平铺半透明深色圆角矩形（ShopPanelBg #1A3037 @ 0.5，贴合内容、面板自身无阴影；阴影只属于内容：红卡/按钮/名牌带）。面板内：左 3 张红色关键卡（硬阴影，hover 弹起，点击放大，无伤害数字）+ 右侧敌方名牌与【选择 +$N】同宽同右缘（卡顶 = 名牌顶，卡底 = 按钮底，对齐参考 mockup 图三）。名牌样式移植自 HPNamePlateDemo.html，阴影带透明度 0.5（对齐引擎实测渲染：引擎 Image 名义 0.698，经九宫格 sprite 衰减后实际 ≈0.45-0.5）。面板名牌与战斗名牌同字号（34px），morph 飞行为纯平移无缩放。无标题/提示语/页签；选敌页最下面一行留给玩家名牌 + 选项按钮（= 战斗位）。

入场方式（参数栏可切换对比）：原位 morph（默认·推荐）——点选后镜头不动：背景 HP bar 敌方红带回退、玩家灰区上长，被选名牌直飞战斗右上位（同时放大到战斗名牌尺寸），其 3 张关键卡弧飞入牌堆后方（中点翻背），玩家卡组卡从商店行弧飞入堆——与玩家侧同款处理；被选对象全程在屏，身份连续，且战斗页不再需要 +2 屏（plan §8 的 _combatPageY 上移风险消失）。镜头移动（备选）——leg2 镜头上移到 +2 战斗页（plan 原几何），此时选敌页背景按备选裁定直接玩家/敌人二分（与战斗同款），敌方名牌改为滑入式注入。

待确认：【选择 +$N】的 +$N 语义 demo 按「挑选奖励」占位（演示数据虚构）。操作：商店页点【离开，开始新的一天】或上滑 → 选敌页；点【选择 +$N】（单击即选，O2）→ 战斗；点战斗页【重置演示】回到商店（demo 专用，D4 真机无返回）。切换入场方式会硬重置回商店页。视觉/物理标准 = PhaseTransitionDemo.html / UIKitDemo.html / HPNamePlateDemo.html。

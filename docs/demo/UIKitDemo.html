OneDeck UI Kit — 可交互 UI 规范

本页是 OneDeck UI 交互手感的可执行规范（living document）。顶部参数条实时调整物理手感；页面上显示的数值就是要移植到 Unity（DOTween 时长 / 偏移量）的数值。手感定稿后，把决策沉淀到 docs/UIUX_Guidelines.md。

规则 0（光源）：全局光源在左上。所有可交互元素的"亮面"向上抬起时向左上位移，硬阴影固定在右下的"地面"位置。任何元素（卡牌、按钮、tooltip、弹窗、凹槽）的阴影方向不允许违反这一约定。

物理参数

01 设计令牌 Tokens

v0.1 草案
  • 颜色令牌对应 Unity 侧的 ColorSO / GameColorPalette——实现时只准引用令牌名，禁止写死 hex。
  • 物理令牌（阴影偏移、位移、时长、缓动）见顶部参数条，实时可调；当前值显示在第 06 节的规则正文中。

02 按钮 Push Button

v0.1 草案
  • 四态：静止（带阴影）→ 悬停（向左上升起，阴影留在原地）→ 按下（落到阴影上，阴影消失）→ 松开激活。
  • 按住时移出元素 = 取消（松开不触发）；保持按住移回 = 重新按下。
  • 激活时机在松开，不在按下——给取消留机会。
  • 禁用态：暗面、无阴影、无悬停响应、cursor: not-allowed。

03 长按卡片 Long-Press Card

v0.1 草案
  • 购买 / 售出是长按操作：按下后进度填充从底部升起，到达阈值立即触发（不等松开）。
  • 未到阈值松开 = 取消；按住移出 = 取消。取消无任何副作用。
  • 卡片的悬停/按下物理与按钮完全相同（同一套 .phys 状态机）。
  • 价格是卡片的只读附属标签，不单独响应交互。
  • 触发确认 = 后果动效本身：触发瞬间不加闪黑/变色等额外效果——购买卡飞入卡组空位、售出卡飞出，位移就是确认。本页暂以"填充走满后短暂停留再消退 + 日志"代替；飞卡动效后续单独一节原型化（时长 / 弧线 / 缓动可调）。

04 悬停提示 Tooltip

v0.1 草案
  • tooltip 触发物不是可点击元素，不使用物理浮起——仅变色 + cursor: help，避免和按钮混淆。
  • 悬停满 tipDelay 后 tooltip 浮现（轻微上移淡入）；移出立即消失。
  • tooltip 本身平面、无阴影物理、pointer-events: none（永不挡交互）。
  • 对应 Unity 侧 CombatUXManager.hoverPopUpDelay 的同类参数。

05 只读元素与凹槽

v0.1 草案
  • 信息展示元素一律平面：无阴影、无位移、cursor: default。"可交互 = 亮面浮起"的逆命题必须成立，否则玩家会对着 HP 数字点半天。
  • 空卡位是凹槽（recessed）：内阴影在左上——与浮起元素相反，符合同一光源。

06 规则与状态矩阵

随参数实时更新
  • R1 光源：全局左上。浮起元素阴影投向右下；凹槽元素内阴影在左上。
  • R2 可交互性：可交互 = 亮面 + 阴影（浮起）；只读 = 平面；禁用 = 暗面 + 无阴影 + 无响应。
  • R3 静止：阴影偏移 。
  • R4 悬停：面向左上位移 ，时长 ；阴影同步增大等量偏移，视觉上固定在地面。
  • R5 按下：面在 内落到阴影位置（落点可用参数切到"回原位"对比手感），阴影归零。按压要脆，时长必须短于悬停。
  • R6 保持与取消：按住不松 = 保持按下态；按住移出 = 取消（松开不触发）；按住移回 = 重新按下。
  • R7 激活时机：点击在松开时触发，不在按下时。
  • R8 长按：阈值 ，进度填充从底部升起，到阈值立即触发，提前松开取消。
  • R9 Tooltip：悬停 后浮现；触发物仅变色，不浮起。

如何新增组件（保持本页可延展）

1) 复制任意 <section data-title> 作为模板（目录会自动收录）。 2) 交互元素加 class="phys" data-interactive 即自动获得悬停/按下/取消状态机；长按加 data-longpress data-lp-action="..."；提示加 data-tip="..."。无需写新 JS。 3) 新全局参数 = 在 PARAMS 数组加一项，参数条、状态对象、规格 JSON 自动生成。 4) 手感确认后，把数值同步进 docs/UIUX_Guidelines.md 与 Unity 实现。

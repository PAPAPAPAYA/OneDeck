OneDeck UI Kit — 可交互 UI 规范

本页是 OneDeck UI 交互手感的可执行规范（living document）。顶部参数条实时调整物理手感；页面上显示的数值就是要移植到 Unity（DOTween 时长 / 偏移量）的数值。手感定稿后，把决策沉淀到 docs/UIUX_Guidelines.md。

规则 0（光源）：全局光源在左上。所有可交互元素的"亮面"向上抬起时向左上位移，硬阴影固定在右下的"地面"位置。任何元素（卡牌、按钮、tooltip、弹窗、凹槽）的阴影方向不允许违反这一约定。

物理参数

01 设计令牌 Tokens

v0.1 草案
  • 颜色权威在 Unity 侧：本文档的 hex 仅为演示站位色，不移植；生产色以 GameColorPalette 为准——每个色板下方标注了对应的 palette 字段与 ColorSO 资产，实现时只准引用字段名，禁止写死 hex。
  • tooltip 底/字 = tooltipBg/tooltipText（Navy/GreyWhite）；价格与数字强调 = highlight（LogHighlight #FFEB04）。
  • 物理令牌（阴影偏移、位移、时长、缓动）见顶部参数条，实时可调；当前值显示在第 07 节的规则正文中。

02 按钮 Push Button

v0.1 草案
  • 四态：静止（带阴影）→ 悬停（向左上升起，阴影留在原地）→ 按下（落到阴影上，阴影消失）→ 松开激活。
  • 按住时移出元素 = 取消（松开不触发）；保持按住移回 = 重新按下。
  • 激活时机在松开，不在按下——给取消留机会。
  • hover 换文案：静止显示价格，悬停换成动作文案（data-hover-text，示例 $4 → 买入）；文案即时切换不做淡入淡出——浮起动画已经承载了过渡感；点击行为不变，移出恢复原文案。仅用于纯文本面的按钮。
  • 禁用态：暗面、无阴影、cursor: not-allowed；mouseenter 时播放一次拒绝动效（平移出一截 → 摇头 → 停留 → 退回原位），每次进入只播一次，重新进入再播。摇头方式可选左右平移或旋转（旋转幅度独立，单位°），平移出 / 次数 / 单程 / 幅度 / 停留 / 退回均可在参数条配置。

03 卡牌模板 Card Template

v1.1 模板 · 2026-08-18
  • 分区（自上而下）：卡图区（深色圆角，插画预留位）→ 稀有度（卡图右下方，✦×1~3，右对齐）→ 效果描述（自动 > 前缀，最多两行截断）→ 分隔线 → 底行：卡名（左，粗体，过长省略号）＋ 攻击力（右，同基线、更大字号）。
  • 效果描述贴分隔线、从下往上排：稀有度行 flex-grow 吸收弹性留白，效果文案第二行向上生长；无效果卡省略效果行（.card-effect:empty 兜底隐藏，不留孤悬的 >）。
  • 卡面内部尺寸全部基于卡片字号的 em 相对单位——.card-face.zoom 只改字号即整体放大，供解剖展示。
  • 交互物理与按钮完全一致（同一套 .phys 状态机）；价格等商店附属信息挂在卡外，不进卡面。
  • 卡图底色与稀有度星标 = 令牌 --card-art；卡面文字 / 分隔线 = --ink。
  • 待定：实装插画后稀有度星标的可读性。

04 长按卡片 Long-Press Card

v0.1 草案
  • 购买 / 售出是长按操作：按下后进度填充从底部升起，到达阈值立即触发（不等松开）。
  • 未到阈值松开 = 取消；按住移出 = 取消。取消无任何副作用。
  • 卡片的悬停/按下物理与按钮完全相同（同一套 .phys 状态机）。
  • 价格是卡片的只读附属标签，不单独响应交互。
  • 触发确认 = 后果动效本身：触发瞬间不加闪黑/变色等额外效果——购买卡飞入卡组空位、售出卡飞出，位移就是确认。本页暂以"填充走满后短暂停留再消退 + 日志"代替；飞卡与商店↔战斗过场动效见同目录 PhaseTransitionDemo.html。

05 悬停提示 Tooltip

v0.2 草案
  • tooltip 是可交互元素的附属属性，不是独立元素：宿主保持自身 hover 物理（卡片照常浮起），tooltip 在悬停满 tipDelay 后叠加出现；移出立即消失。
  • 位置优先级：宿主左侧、垂直居中 → 左侧视口空间小于 Tooltip 边距 参数则翻转到右侧；垂直方向视口内收拢（硬边距 8px）；宿主移动（窗口 resize / 缩放 / 滚动）时 tooltip 实时跟随重排。
  • 一个宿主可挂多条 tooltip，纵向堆叠（示例卡 B 有两条；条数之后会有硬上限）。
  • tooltip 本身平面、无阴影物理、pointer-events: none（永不挡交互）；内容 = 标签名 + 描述。
  • 对应 Unity 侧 CardTagTooltip（CardPhysObjScript hover 触发）与 CombatUXManager.hoverPopUpDelay 的同类参数。

06 只读元素与凹槽

v0.1 草案
  • 信息展示元素一律平面：无阴影、无位移、cursor: default。"可交互 = 亮面浮起"的逆命题必须成立，否则玩家会对着 HP 数字点半天。
  • 空卡位是凹槽（recessed）：内阴影在左上——与浮起元素相反，符合同一光源。

07 规则与状态矩阵

随参数实时更新
  • R1 光源：全局左上。浮起元素阴影投向右下；凹槽元素内阴影在左上。
  • R2 可交互性：可交互 = 亮面 + 阴影（浮起）；只读 = 平面；禁用 = 暗面 + 无阴影 + 拒绝动效（mouseenter 一次：平移 后摇头 次——方式可选左右平移/旋转——单程 ，幅度 ，停留 再归位）。
  • R3 静止：阴影偏移 。
  • R4 悬停：面向左上位移 ，时长 ；阴影同步增大等量偏移，视觉上固定在地面。
  • R5 按下：面在 内落到阴影位置（落点可用参数切到"回原位"对比手感），阴影归零。按压要脆，时长必须短于悬停。
  • R6 保持与取消：按住不松 = 保持按下态；按住移出 = 取消（松开不触发）；按住移回 = 重新按下。
  • R7 激活时机：点击在松开时触发，不在按下时。
  • R8 长按：阈值 ，进度填充从底部升起，到阈值立即触发，提前松开取消。
  • R9 Tooltip：可交互元素的附属属性（宿主保持自身 hover 物理），悬停 后浮现；位置 = 宿主左侧垂直居中，左侧间隙小于 翻转右侧，视口 8px 硬收拢；宿主移动时跟随重排；单元素可挂多条纵向堆叠。

如何新增组件（保持本页可延展）

1) 复制任意 <section data-title> 作为模板（目录会自动收录）。 2) 交互元素加 class="phys" data-interactive 即自动获得悬停/按下/取消状态机；长按加 data-longpress data-lp-action="..."；提示加 data-tips='[["标签","描述"]]'（可多条）；悬停换文案加 data-hover-text="..."。无需写新 JS。 3) 新全局参数 = 在 PARAMS 数组加一项，参数条、状态对象、规格 JSON 自动生成。 4) 手感确认后，把数值同步进 docs/UIUX_Guidelines.md 与 Unity 实现。

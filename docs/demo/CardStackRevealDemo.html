OneDeck 悬浮揭示堆叠排列 Demo

目标排列描述：卡组直接堆叠，不设横向扇形偏移；越往后的卡越高，每张抬高固定步长（stackStepY，可调，支持负数 = 向下堆叠）。最前方是被揭示的卡：放大一定倍率（可调），并向左上偏移悬浮。揭示卡带一个卡形阴影，阴影大小与揭示卡相同（同步缩放倍率）；阴影的位置就是整套排列的锚点 —— 揭示卡的左偏移（floatX）和上偏移（upY）都直接基于阴影位置，后面的堆叠卡也基于阴影位置做 y 轴逐级偏移。整体效果：揭示卡悬浮在卡组上方。

揭示流程（点「揭示下一张」或点击演示区）：当前揭示卡的阴影渐变消失，同时该卡缩小并飞向卡组最后面（最高槽位 = 牌库底）；堆叠卡整体下滑一级；新的牌库顶放大、向左上偏移完成揭示 —— 阴影从该卡在卡组中的位置和大小出发，与揭示动画同步放大并移动到锚点最终位置。牌序映射：揭示卡 = combinedDeckZone[Count-1]（牌库顶），堆叠第 1 级 = 下一张，最高槽位 = combinedDeckZone[0]（牌库底）—— 与 reveal→bottom 语义同构。

位置计算（Unity 映射）

  • 锚点 = 阴影位置 = physicalCardDeckPos；所有卡位都是锚点 + 固定偏移的纯函数
  • 堆叠卡 i（i=1 为下一张）：offset = (0, −stepY·i)；揭示卡：offset = (−floatX, −upY)，scale = revealScale（阴影同 scale）
  • 可并入 DeckPositionCalculator 作为第三种布局模式；揭示卡即 reveal-zone 等价物

层级与牌序

  • z 序：揭示卡 > 阴影 > 堆叠第 1 级 > … > 最高槽位（牌库底）
  • 揭示传送带：揭示卡归位到最高槽位（index 0），其余每卡降一级，与 MoveCardToBottom 语义同构
  • 阴影是独立视觉元素：揭示卡归位时渐隐，新卡揭示时在锚点淡入

与现有 cascade / arc 的差异

  • 最简布局：无缩放衰减、无曲线、无弧长表，偏移是分段线性纯函数
  • 阴影元素需要在 ICombatVisuals 增加一个 reveal 阴影槽（或在 CardPhysObjScript 上挂剪影子物体）
  • 堆叠只露底边一条缝，卡面信息全被遮挡，读牌依赖揭示卡本身
  • 牌很多时总高度 = stepY·(N−1)，需要按 deckSize 上限核算屏幕占位

OneDeck 悬浮揭示堆叠排列 Demo

目标排列描述：卡组直接堆叠，不设横向扇形偏移；越往后的卡越高，每张抬高固定步长（stackStepY，可调，支持负数 = 向下堆叠）。锚点 = 卡组中心（置于屏幕中心）：任意卡片数量下，卡组关于锚点上下对称居中。一切从阴影的家推导：阴影家 = 栈底 slot 0（最低卡再向下一级）+ shadowOffset，随居中/钉底的栈底移动；被揭示的卡 = 阴影家 + (−floatX, −upY)，放大一定倍率（可调）—— 默认 upY = −14，揭示卡沉在栈底之下，是整组卡组的最低元素（拖回 70 = 原版悬浮构图）。阴影大小与揭示卡相同（同步缩放倍率），与揭示卡保持恒定偏移（绑定），整段揭示飞行同步移动。整体效果：揭示卡在卡组最下方悬浮。

大卡组自适应（新增）：① 压缩：当 stepY·卡组数 超过 maxHeightPx 时，全局缩放 globalScale = maxHeightPx / (stepY·卡组数)，钳制在 [minScale, 1] —— 只缩不拉，小卡组保持自然步长；步长与缩放绑定（有效步长 = stepY·globalScale），总高真正被压进 maxHeightPx。② 下探极限：所有卡面的最低点（卡组视觉底边与揭示卡底边取更低者；阴影是软元素，允许越线）低于锚点超过 bottomLimitPx 后，整栈抬升把最低点钉在极限处（红色虚线），卡面主体完全不越线，之后卡组只向上长、不再处理。两个参数设为 0 即关闭，退回纯居中行为。卡组缩回时 lift 连续退回 0，自动回到居中。

揭示流程（点「揭示下一张」或点击演示区）：当前揭示卡的阴影渐变消失，同时该卡缩小并飞向卡组最后面（最高槽位 = 牌库底）；堆叠卡整体下滑一级；新的牌库顶放大、向左下偏移完成揭示 —— 阴影从该卡在卡组中的位置和大小出发，与揭示动画同步放大并移动到栈底 slot 0 的最终位置。牌序映射：揭示卡 = combinedDeckZone[Count-1]（牌库顶），堆叠第 1 级 = 下一张，最高槽位 = combinedDeckZone[0]（牌库底）—— 与 reveal→bottom 语义同构。

下探极限

位置计算（Unity 映射）

  • 锚点 = 卡组中心 = physicalCardDeckPos（置于屏幕中心）；堆叠卡位 = 锚点 + 纯函数偏移
  • 堆叠卡 i（i=1 为下一张）：y = step·(n/2 − i) − lift；揭示卡 = slot 0 + (−floatX, −upY)，slot 0 = step·(n/2) − lift（栈底/阴影家）
  • 阴影家 = slot 0 + shadowOffset，与揭示卡保持恒定偏移（绑定），scale = revealScale·globalScale，揭示飞行全程同步
  • frame：globalScale = clamp(maxHeightPx / (stepY·deckCount), minScale, 1)；step = stepY·globalScale；lift = max(0, max(卡组底边, 揭示卡底边) − bottomLimitPx)（约束所有卡面最低点；阴影允许越线）
  • 可并入 DeckPositionCalculator 的 FloatStack 分支；揭示卡即 reveal-zone 等价物

层级与牌序

  • z 序：揭示卡 > 阴影 > 堆叠第 1 级 > … > 最高槽位（牌库底）
  • 揭示传送带：揭示卡归位到最高槽位（index 0），其余每卡降一级，与 MoveCardToBottom 语义同构
  • 阴影家 = 栈底 slot 0，随居中/钉底的栈底移动；揭示卡归位时渐隐，新卡揭示时从其在卡组中的位置同步飞入

大卡组三段行为

  • 小卡组：纯居中，scale = 1，揭示卡+阴影在栈底之下悬浮
  • 中卡组：步长与缩放绑定压缩，总高 ≈ maxHeightPx，minScale 触底
  • 大卡组：所有卡面最低点（含揭示卡）钉在 bottomLimitPx，卡面不越线，只向上长；缩回自动回居中
  • 堆叠只露底边一条缝，卡面信息全被遮挡，读牌依赖揭示卡本身

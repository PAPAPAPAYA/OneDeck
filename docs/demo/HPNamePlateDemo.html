Notes

	
    
		
  • Geometry defaults are pixel-measured from the mockup: face #D1CDC8, ink #1A3037 (== palette Navy / hpNormalPlayer), max group at 0.47 scale raised 0.05em off the baseline, the slash at the full digit size (user ruling 2026-10-07), name cap height 0.32 scale, name right edge aligned with the face's right edge.
    • 
		
  • The username band is not a colored region — it IS the standard hard UI shadow (GameColorPalette.cardShadow = "Navy Alpha" #1A3037 @ 70%, the same PaletteTint slot the world buttons use), extended downward to hold the name. It composites over whatever is behind it; no new palette color is introduced.
    • 
		
  • Both sides share the identical layout: the R0 light source is top-left (docs/UIUX_Guidelines.md, inviolable), so every shadow extends down-right — no mirroring. The enemy plate differs only by face/ink colors: face = hpBarEnemy (Red 2 #801424), ink = hpNormalEnemy (GreyWhite 2 #BFBDB5).
    • 
		
  • Carried over from HPNumericDisplayHorizontal: adaptive counting with ease-out finish, odometer digit roll on both digit groups, hit shake (amplitude scales with damage), landing pop, digit-growth glide (99 → 100). Motion constants unchanged.
    • 
		
  • New: HP label at current-digit size; avatar + separate name label are gone — the username lives in the extended shadow band; hit shake / landing pop now move the whole merged element. The slash stays at the full digit size (unchanged from today's behavior — only the max group renders small).
    • 
		
  • Not carried over (same as the current horizontal version): low-HP red pulse, zero-out drop.
    • 
		
  • Empty username falls back to ??? (same as the retired CombatIconPresenter). Long names shrink to a 55% floor, then ellipsize.

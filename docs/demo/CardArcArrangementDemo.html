OneDeck 圆弧发牌排列 Demo

目标排列描述：参考图展示的是一种「椭圆弧循环队列（Elliptical Arc Loop）」。卡片沿一整条椭圆弧分布，槽位按「弧长 + 曲率加权密度」排布（弯折越剧烈的地方卡越密）。牌库顶（下一张要揭示的牌）= 整圈视觉最低、最前方的卡；牌库底（combinedDeckZone[0]）= 沿弧与它相邻的下一张卡 —— 也就是卡片被揭示、触发效果后要回到的位置。牌序从牌库底沿右侧上行、越过圆弧顶端、沿左侧下行，回到牌库顶。

揭示流程 = 循环传送带：牌库顶飞出 → 落到牌库底的位置 → 其余每张牌沿弧前进一格。z 序按高度：越低越靠前，同层左压右。纵深缩放：按屏幕高度归一 —— 最低（最前）= 1.0，最高（最后）= 后方最小缩放，与 z 序同源。倾斜角：整圈在屏幕平面内刚性旋转（正值 = 左半低、右半高），不做锚定；牌库顶槽位自动对准倾斜后整圈的视觉最低点。弯处加密：槽位沿弧按密度 1 + w·κ/κ̄ 分布，w = 0 时等弧长均匀分布，w 越大弯折处（曲率大）越密。卡片自身始终保持竖直。圆弧的两根轴（radiusX / radiusY）可独立调整；「轮廓方度」在标准椭圆（2.0）与更接近参考图「两侧近似竖直列」的方圆轮廓（>2）之间连续过渡。

位置计算（Unity 映射）

  • 弧长 + 曲率采样表（720 点）+ 二分查找；形状参数变化才重建，倾斜/牌数变化只重查表
  • 槽位按密度 1 + w·κ/κ̄ 沿弧分布：w = 0 等弧长，w 越大弯折处越密（κ̄ = 2π/L）
  • 纵深缩放 = 1 − (1−minScale)·f(高度归一 t)，最低 = 1，最高 = minScale，与 z 序同源
  • 倾斜 = 面内刚体旋转（不锚定），牌库顶槽位以加权弧坐标对准视觉最低点，卡片不旋转
  • index = Count-1（牌库顶）→ 整圈视觉最低点；index = 0（牌库底）→ 沿弧相邻下一槽
  • 可并入 DeckPositionCalculator；弧长缓存模式与 DeckCascadeLayout 同款

层级与牌序

  • z 序只由高度决定：越低越靠前（牌库顶 z 最高，弧顶最低）
  • 同层左右不互相遮挡（radiusX 足够时），约定同层左压右
  • 揭示 = pop 弧底 + insert 到 index 0，所有卡沿弧走一格，与现有 MoveCardToBottom 语义完全同构

与现有 cascade 的差异

  • 缩放只随视觉纵深（角距离）变化：无 per-index 间距衰减、无覆盖率归一化
  • 牌数变化只改加权步长 D/Count，整副牌始终铺满整圈
  • 牌很多时（>20）弧底附近相邻卡角距小，牌库底会几乎被牌库顶完全遮挡
  • 横向占位随 radiusX 增大，注意与 reveal zone / 手牌区的屏幕分区

Result 统计面板 v2 — 迭代 UI Demo

对象:战斗结束(Result 阶段)的 per-card 统计面板。现状 = 上下两半 YOU/ENEMY + 10 列缩写表格(见 03 对照)。本页为迭代版静态原型,数据全部虚构。

迭代要点:

  • 10 项统计全保留,按类别分 3 个 Tab:输出 / 强化 / 操控 —— 一屏只看一类,不再有 10 列缩写表头;
  • 图形化:伤害 = 比例条形 + 数值 + 半区占比;攻击强化 = ↑↓ 箭头数值;操控 = 计数 chips,零值自动淡化;
  • 全零行降级:进场但从未触发的卡收敛为「未触发」弱行,不再是一排同样权重的 0;
  • 半区头部给合计:占比的分母可见,每张卡的贡献有据可查;
  • 阵营色沿用 GameColorPalette(我方灰白 / 敌方红),面板语言沿用 UIKitDemo.html 纸面 + 硬阴影 + 物理按钮。

范围说明:仅统计面板本体;Result 页其他元素(回到商店按钮、头像/HP 等)不在本 demo 内。Tab 可点击切换,但三个 Tab 状态已静态平铺,不点也能评审全部内容。

01 主面板 · 三个 Tab 状态

同一份数据 · tab 可点击切换
Tab:输出 — 伤害比例条(按半区最大值归一)+ 数值(半区占比)+ 触发计数
Tab:强化 — ↑ 给予攻击 / ↓ 获得攻击(强化橙)+ 生成计数
Tab:操控 — 埋葬 / 复活计数 chips,零值自动淡化

02 边界状态

少卡 / 多行 / 长名 / 零数据
少卡 — 每半区仅 1 种卡,面板收紧不撑高
多行 — 半区 12 种卡,行区定高滚动 + 底部提示
超长卡名 — 名称列定宽省略号,数量后缀保留,条形被压缩仍可读
半区零数据 — 无记录半区显示占位;从未触发的卡 = 「未触发」弱行

  • 缩写表头:Dmg>Opp / Bury>F / Trig 等 10 个缩写需要记忆成本,新玩家读不懂;
  • 无视觉锚点:所有列等宽等权重,贡献度对比(谁是输出核心)靠逐格心算;

  • 零值噪声:全零行(石盾卫)与有数据行同样权重,越打越长的列表里有效信息被稀释;
  • 占比无分母:百分比的黑盒 —— 看不到半区总伤害,占比无法验证。

04 数据映射(移植规格)

对应 CombatStatRegistry / CombatPerCardStatsTracker
CombatStatType现表头v2 Tabv2 图形形式颜色
DamageDealtToOpponentDmg>Opp输出比例条(半区最大值归一)+ 数值 + 半区占比伤害红
TriggerCountTrig输出计数 chip「触发 ×N」—
AttackGivenAtkGive强化「↑ N」箭头数值强化橙
AttackReceivedAtkRecv强化「↓ N」箭头数值强化橙
CardsGeneratedGen强化计数 chip「生成 N」—
FriendlyBuriedBury>F操控计数 chip「葬友 N」—
EnemyBuriedBury>E操控计数 chip「葬敌 N」—
TimesBuriedBuried操控计数 chip「被葬 N」—
RevivesTriggeredRevive操控计数 chip「复活 N」—
TimesRevivedRevived操控计数 chip「被复活 N」—
  • DamageDealtToSelf / PowerGiven / PowerReceived 维持 showInResultPanel = false,继续记录不显示;
  • 排除规则不变:中立卡(IsNeutralCard)与 Utility Passive 不进表;
  • 卡名后缀 (X) = 初始卡组同名牌数量,仅 X ≥ 2 时显示(与现状一致);
  • 占比 = 该行该列值 ÷ 本半区该列合计;值为 0 时不显示占比;半区合计显示在半区头部;
  • 每个 Tab 内行排序 = 该 Tab 主指标降序(输出:伤害 → 触发;强化:给予+获得;操控:五类合计);
  • 全零行(所有统计均为 0)= 「未触发」弱行,整行降透明度,不渲染统计格;
  • 阵营归属 = 卡牌创建方(creatorSide),与现状一致:玩家生成的敌方诅咒归 YOU 半区。

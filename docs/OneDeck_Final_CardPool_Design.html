PART A · 最终卡池设计

A1. 核心规则与数值经济

规则定义
战斗模型1v1 玩家 HP 对决:双 deck 合并洗牌,一卡一卡揭晓;攻击伤害结算到敌方玩家 HP;卡无生命值(不能被伤害,只能被 埋葬 / 置顶 / 沉睡 / 降攻 / 去除);无多目标 —— 「全体敌人受到伤害」语义不存在
三个动作揭晓(结算效果)→ 进墓地;置顶(插队提前揭晓,触发「被置顶」事件);埋葬(送进墓地 = 控制 + 计数 + 触发「被埋葬」事件)
数值经济唯一数值 = 攻击力(卡面基础 + 永久成长);攻击 = 攻击力 × 段数;易伤 = 敌方每段受到的攻击伤害 +1;攻击 +N 次 = 第一乘区授予
沉睡(离场待机)沉睡中的卡离开牌库进入【沉睡区】(独立区域:不占用揭晓顺序、不计入墓地、不触发亡语)—— 类似一直被埋葬,不会堆积在 Start Card 前;牌库中的沉睡卡到达揭晓位时自动移入沉睡区,不消耗本次揭晓;唤醒条件满足时(每回合开始检查)回到牌库准备位(下次揭晓结算);[沉睡]tag 定向效果(枕边低语 / 晨钟 / 大觉醒 / 守夜人 / 梦呓 / 安眠)可指定沉睡区卡;因不在牌库,天然免疫置顶与埋葬(王座区 / 乱葬坑不会触及);敌方卡同样可被沉睡(唤醒条件如「主人受到 3 次伤害」)
王座区「Start Card 前 N 张」位置谓词 —— 牌库最尾段(最晚揭晓),后期大怪调度区
结构规则12 卡位上限(仅商店);combat 生成卡不受限;疲劳(总揭晓数)节流;链系统(同卡同效果一链一次 + 深度 99)防无限;Start Card always bottom
禁止项去除敌方[次元裂缝];「全体敌人」伤害类效果;卡牌生命值/随从(无对应模型)

关键词表(最终)

关键词定义
攻击造成 X 点伤害,X = 卡面攻击力(含永久成长,每段计入);动态攻击力(攻击力 = Y)常态结算
攻击 ×NN 段攻击(每段独立结算)
攻击 +N 次该卡每次揭晓的攻击段数永久 +N(可叠加)
攻击力 = Y结算时攻击力实时取 Y(常态结算;可读敌方侧状态)
+N 攻击力卡面攻击力永久 +N(可叠加)—— 原「力量」「攻击力成长」合并
增强敌方[负面]/[诅咒] 攻击力 +1(不存在时自动生成 JU_ON)
易伤敌方每段受到的攻击伤害 +1(可叠加,永久)
沉睡 / 唤醒见 A1 规则
亡语被埋葬时触发(可被「直接触发」—— 招魂者)
萦绕常驻事件触发器(每当 X:收益)
位置谓词(最高攻击力)/(最低攻击力)/(最深)/(下 N 张)/(Start Card 前 N 张)

PART B · 平衡性与可行性分析

B1. 战斗模型约束(可行性根因)

OneDeck 的合法交互面只有三面:① 敌方玩家 HP(伤害);② 敌方卡状态(攻击力增减 / 沉睡 / 置顶 / 埋葬 / 延迟);③ 牌库位置(置顶 / 王座区 / 交换)。任何卡设计必须落在三面内;从 StS2 借用的机制需要先做映射检查。
StS2 概念OneDeck 映射结论
多目标伤害(全体敌人 / AoE)不存在 —— 敌方只有一个玩家,卡无生命值不可行:战旗原案「攻击全体化」否决,重做为「攻击附带削攻」(每次攻击随机敌方[攻击者]攻击力 -1)—— 1v1 模型下「攻击打到所有敌方攻击者」的等价语义是「每次攻击都在拆敌方攻击者」
卡牌生命值 / 随从受击不存在 —— 卡只能被埋葬 / 去除,不能受伤不可行:所有「对敌方卡造成伤害」类设计禁用;只能用 攻击力-1 / 沉睡 / 埋葬 表达
群体 buff(全角色)可映射(全体友方[攻击者])可行,但稀有度按档位基准线(见 B2)—— 集结号因此从 C 上移 U
触发次数 +1(Accelerant)亡语额外触发 / 被置顶额外触发可行(墓园共鸣 / 回声)
群伤化(Fan of Knives)无对应重做(战旗)
敌方降攻(Enfeebling Touch)敌方[攻击者] 攻击力 -N可行,但永久版过强 → 虚弱诅咒改为「本回合」
沉睡 / 控制跳过揭晓与效果可行(己方 / 敌方)
动态攻击力(攻击力 = 存量)常态结算,可读墓地 / 友方 / 敌方[负面]可行(王牌 / 战争英雄 / 镜面诅咒 / 全能人)

卡问题修正
集结号C 卡永久「所有友方[攻击者] +1 攻击力」:收益 = 攻击者数 × 揭晓频率,5 攻击者时每轮 +5~10 伤害,永久叠加 —— 乘法级收益放 C 档上移 U(与嗜血 / 军火库同族:全体授予在 U/R 档);数值保持 +1

B5. 开放问题

  • 自动机批次(10 张)的强度面:暮鼓 / 号角长鸣 / 弱点解析 都是「每回合稳定积累」,回合数越长越强 —— 与疲劳节流配合;若实测过强,改「每 2 回合开始」或数值减半。
  • 萦绕卡「游戏开始即生效」规则确认:被埋葬即失效(自动机同理),安眠是唯一保护手段 —— 确认这是期望的脆弱面。
  • C 档 15.9% 是否过薄:3 张沉睡教学 + 3 张授予卡上移后的结果;若实战发现入口密度不足,可把 深埋 / 掘墓人 类工具留在 C 并新增 1-2 张 C 入口。
  • 战旗新数值:「每次攻击削 1 攻」的实测;若过强,改「每回合首次攻击」或「攻击 ×2 卡才触发」。
  • 沉睡区语义(新):沉睡卡离开牌库进独立沉睡区,不计入墓地 —— 若希望沉睡卡「类似一直被埋葬」计入墓地计数(喂人间大炮 / 尸眠),需另行确认(当前设计为不计入,防堆墓地利用)。
  • 沉睡区交互面:枕边低语 / 晨钟 / 大觉醒 / 守夜人 / 梦呓 / 安眠 可指定沉睡区卡 —— 其他「给予友方卡」类效果(铁匠等)是否也可指定,建议默认不可以。
  • 铁匠作为 C 档唯一永久授予:保留或临时化的最终裁决。
  • 攻击 +N 次的实现:CardScript 新字段 + 多段动画性能(v4 遗留)。
  • 王座区谓词:引擎支持「Start Card 前 N 张」的定位与区域 buff。
  • 入库:23 张新卡 + 6 重做 + 5 修正尚未同步 Notion,确认后统一同步。

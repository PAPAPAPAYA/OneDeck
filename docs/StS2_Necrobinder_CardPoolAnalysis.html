0. 角色骨架

  • 属性:66 HP(全角色最低)、3 能量、起始遗物 Bound Phylactery(每回合开始 Summon 1)。
  • 起始牌组(12 张):Strike ×5、Defend ×5、Bodyguard ×1、Unleash ×1 —— 相当于「迷你 Barricade + 迷你 Body Slam」直接内置于初始卡组:Bodyguard 每回合给 Osty 加血(遗物再 +1),Unleash 按 Osty 当前 HP 打伤害。这是全游戏强度最高的起始模板之一。
  • 战斗伙伴 Osty(巨型骨手):起始 1 HP;「Die for You」 拦截所有未格挡的攻击伤害(溢出部分才打到你)= 第二条血条;攻击全部由卡牌驱动,不吃 Necrobinder 自身的力量 / 虚弱 / 易伤(但吃 Calcify 等 Osty 专属加成);死亡后由下一次 Summon 以 1 HP 复活。
  • 卡池组织方式:四类「条件资源」(Doom 阈值 / Soul 频率 / Osty 血条 / Ethereal 计数)+ 一张把它们互相接通的桥梁网络。没有任何一张卡是纯孤岛,这是本拆解的核心结论。
  • 多人模式内容:当前卡池含 5 张多人模式专属卡(Cacophony / Soulbound / Underworld / Glimpse Beyond / Legion of Bone),机制围绕「ALL players」展开 —— 玩家之间的攻击、抽牌、Soul 产出互相喂给对方(见各轴小节标注 多人)。
资源轴速览:Doom = 阈值资源(叠到 ≥HP 即处决);Soul = 频率资源(0 费抽 2 的 token,打出次数即收益);Osty HP = 蓄水池资源(防守即成长);Ethereal = 计数资源(打出/抽到次数换倍数)。

1. 条件体系:有什么条件、怎么满足、换来什么

Necrobinder 卡池的「条件」可归为五组。每行按 条件 → 判定方式 → 满足(制造)手段 → 兑现(收益) 展开。

1.1 A 组:敌人身上的状态积累(Doom 阈值系)

条件判定时机由哪些卡满足(制造)兑现收益
敌 Doom ≥ 当前 HP 敌人回合结束时(对玩家自身同样生效) Blight Strike(伤转 Doom)、Scourge、Negative Pulse、Deathbringer、Countdown(每回合自动机)、No Escape、Oblivion、Reaper Form(攻击附 Doom)多人 Underworld(队友攻击附 Doom) 即死处决:无视格挡、无视阶段转换(跳过 BOSS 变身/分裂)、不触发受伤类效果、Doom 不衰减
敌已有 Doom 量 施放时实时读取 任意 Doom 源先叠底 No Escape:每已有 10 点 Doom 额外 +5(增幅循环,越叠越快)
本回合已施放过 Doom 回合内布尔判断 任意 Doom 源(哪怕 1 点) Death's Door:格挡 6 额外再结算 2 次 = 18 格挡
敌人带着 debuff 持续状态 Fear / Defy / Putrefy / High Five / Deathbringer / Doom 本身 Sleight of Flesh(每次施放 debuff 造成 9 伤)、Misery(扩散到全敌)、Debilitate(易伤/虚弱效果 ×2,持续 3 回合)
Doom 的关键性质:不随时间衰减、不吃格挡、不触发「受伤/被攻击」类反应 —— 它只做一件事:把「敌人还活着」变成一个倒计时。设计上 Doom 轴的全部压力都在防守端(拖到回合结束),因此该轴自带一整排防御件(Shroud / Death's Door 系)。

1.2 B 组:Osty 的存活与行动状态

条件判定方式满足手段兑现收益
Osty 存活 持续状态 任何 Summon 效果复活/维持(死亡后下一次 Summon 以 1 HP 复活) Bone Shards(全敌 9 伤 + 9 格挡,随后牺牲 Osty)、Sacrifice(Osty 死亡,获得 3× 最大 HP 格挡)、Unleash / Protector 的伤害部分
Osty 本回合已攻击过 回合内计数 Poke / Fetch / Snap / Unleash / Sweeping Gaze 等任意 Osty 攻击卡 Flatten 0 费化(2 费 → 0 费,12 伤)、Rattle 额外段数(每已攻击 1 次 +1 段)、Sic 'Em 每击中 1 次 Summon 3
Osty 当前 HP / 最大 HP 的大小 实时读取 所有 Summon 效果 + 遗物(蓄水池越大越好) Unleash(伤害 = 6 + 当前 HP)、Protector(伤害 = 10 + 最大 HP)、Sacrifice(格挡 = 3×最大 HP)、Necro Mastery(Osty 每次掉血,全敌同步掉等量 HP)
Osty 轴的特殊性:血条本身就是防守收益(拦截攻击),所以「养 Osty」不需要额外的防御卡投入 —— 这是 Necrobinder 前期的经济性来源。

1.4 D 组:玩家自我付出的代价(负资源换正资源)

1.5 E 组:牌库 / 手牌工程

条件满足手段收益
弃牌堆里有卡 任何打出的卡 Dredge 捡 3 张上手(消耗)、Graveblast 捡 1 张(伤害附带)、Drain Power 随机升级 2 张

2. 收益体系:条件被满足后,卡池提供哪五类回报

收益类型定义代表兑现卡

② 伤害四种形态:直伤、Osty 伤害(不吃己方力量,吃 Calcify)、反射(敌掉血同步)、无消耗扣血Reap / Bury(直伤)、Unleash / Protector / Squeeze(Osty)、Necro Mastery(反射)、Haunt / Sleight of Flesh / Capture Spirit(扣血)

3.2 每档稀有度的设计职责

档位承载功能代表卡
Basic 轴种子:把两条轴的最小可用单位直接塞进起始牌组 Unleash(Osty 伤害种子)、Bodyguard(Osty 血条种子)
Common 轴入口 + 基础攻防:每张 Common 都是「一张卡 + 一个条件制造动作」。没有能力卡 —— 全部即打即用,零成长承诺,帮助玩家在无信息压力下学会「制造条件」 Doom 入口 ×3(Blight Strike / Scourge / Negative Pulse)、Soul 入口 ×2(Reave / Grave Warden)、Osty 入口 ×4(Poke / Snap / Flatten / 血条系)、Ethereal 入口 ×2(Sculpting Strike / Defile)、能量 Wisp
Uncommon 主轴组件 + 第一轮封顶:能力卡登场(自动机、放大器、防御件),量产件出现;同时也是桥梁最密集的档位(跨轴连接卡大多在这里) Countdown(自动机)、Calcify(放大器)、Shroud / Danse Macabre(防御件)、Capture Spirit / Severance / Dirge(量产)、No Escape(增幅)、Deathbringer / Bury / Pull from Below(第一轮封顶)、Sleight of Flesh(桥)
Rare 封顶件 + 转换件 + 引擎:大数字(处决、52 伤、Summon 20)、轴间转化(攻击→Doom、Soul→Osty)、以及把整个牌组转速拉起来的引擎 End of Days(处决)、Reanimate / Sacrifice / Banshee's Cry / Bury 系、Reaper Form / Devour Life / Necro Mastery(转换)、Demesne / Neurosurge / Call of the Void / Eidolon(引擎)
Ancient 轴封顶的极端化 + 永久牌库工程 Protector(Osty 伤害 = 10 + 最大 HP)、Forbidden Grimoire(Eternal,永久移除卡)
结构性结论:稀有度 = 「入口 → 组件 → 封顶」的递进。Common 无能力卡是刻意的 —— 新玩家在前期学会「制造条件」,中期(Uncommon)拿到自动机把条件自动化,后期(Rare)拿到封顶件把条件兑换成大数字。桥梁卡集中在 Uncommon(前期就能串轴)+ Rare(后期才允许轴间转化)。

4. 五条轴与构筑关键卡

4.1 Doom 轴(阈值 / 处决)

施放 Doom → 叠到 ≥ 敌当前 HP → 敌回合结束即死(无视格挡) → 防守拖回合 → 继续叠下一只
环节卡作用
入口Blight Strike ★ / Scourge ★ / Negative Pulse伤转 Doom、纯 Doom + 过牌、群 Doom + 格挡 —— 前期的三选一标配
自动机Countdown ★每回合开始白送 6 Doom(升级 9),Doom 轴的中期发动机
增幅No Escape ★每已有 10 Doom 再 +5 —— 叠 Doom 的速度本身是乘区
群上Deathbringer全敌 21 Doom + 虚弱,一卡启动全屏倒计时
增量引擎Oblivion ★ / Reaper Form0 费:本回合每打 1 张牌 +3 Doom(与 0 费连打联动);攻击造成伤害附等量 Doom(把攻击流整体转进 Doom)
防御件Shroud ★ / Death's Door施放 Doom 得格挡(与 Countdown 联动 = 每回合免费格挡);本回合施放过 Doom 则 18 格挡
封顶End of Days ★ / Time's Up ★全敌 29 Doom + 立即处决已达标者;Doom 存量转即时伤害,不再消耗 → 可重复使用,Doom 越高越接近「每回合白打一次大数字」
多人Underworld 多人本回合队友每次攻击造成伤害 → 附加等量 Doom;多人局把整队的攻击输出变成 Doom 增速器
构筑关键卡:Blight Strike、Scourge、Countdown、No Escape、End of Days、Time's Up、Shroud
引擎形态:Blight Strike / Reaper Form(攻防一体地叠 Doom)+ Countdown + No Escape 的「增幅循环」+ Shroud 的自给防守 —— Doom 轴是五轴中最不需要额外攻击卡的一轴,叠层本身就是输出。

4.2 Soul 轴(频率 / 过牌)

生成 Soul → 打出 Soul(0 费,抽 2,消耗)→ 每次打出触发 Haunt / Devour Life → Soul 进消耗堆喂养 Soul Storm
环节卡作用
入口Grave Warden ★ / Reave格挡 + Soul(公认最强普卡,攻防过牌三合一);伤害 + Soul
量产Capture Spirit ★ / Severance ★ / Dirge ★ / Glimpse Beyond 多人无伤扣血 + 3 Soul;13 伤 + 三区各 1 Soul;X 费 Summon 3X + X Soul(双轴);全玩家 +3 Soul

兑现Haunt ★ / Soul Storm ★ / Devour Life ★每次打出 -7 HP(频率形态);每张存量 +4 伤(存量形态);打出 Soul → Summon(转 Osty 轴)
多人Soulbound 多人选择一名队友:你每生成 1 张 Soul,他牌组 +1 Soul —— 把 Soul 频率转成跨玩家资源
构筑关键卡:Grave Warden、Capture Spirit、Severance、Dirge、Seance、Haunt、Soul Storm、Devour Life
引擎形态:Grave Warden / Capture Spirit / Severance 制造 Soul → 打出即抽 2 → Haunt 每次 -7 HP + Devour Life 喂 Osty。Soul 轴的本质是「把过牌本身变成伤害/成长」,循环越快收益越高,是高层进阶最强形态。

4.3 Osty / Summon 轴(蓄水池 / 第二条血条)

7. 设计观察(设计视角总结)

  1. 条件资源化,收益两段式:每张轴入口卡只负责「制造条件 + 基础攻防」,条件兑现全部交给独立兑现卡(Haunt / Soul Storm / End of Days / Pull from Below)。这保证了入口卡单张不超模,兑现卡单独抓取时无用 —— 迫使玩家跨卡组牌。
  2. 桥梁网络是卡池的骨架:Dirge / Reaper Form / Devour Life / Necro Mastery / Sleight of Flesh 五张桥,把四条轴连成环。任何两条轴都能互喂,构筑自由度来自桥梁密度而非单卡强度。
  3. 自我代价 = 能量来源(两代形态):第一代是「自 Doom」(Neurosurge —— 拿能量,攒倒计时);第二代是「透支」(Borrowed Time —— 拿 4 费,本回合全卡 +1 费)。两种都是「现在多打,之后还」的句式,风险兑现时点不同。
  4. 稀有度分层 = 学习路径:Common 全无能力卡、Uncommon 给自动机与桥梁、Rare 给封顶与转换 —— 玩家先学会制造条件,再学会自动化,最后学会兑换。
  5. 处决机制解决"防御端无限成长"问题:Doom 无视格挡与阶段转换,是对「叠甲型 / 多阶段 BOSS」的专用反制;作为代价,它要求玩家自带防守拖回合 —— 一轴同时承担进攻与防守叙事。
  6. 新版补丁的三个方向:① 泛用卡贴 Ethereal 标签(Fear / Lethality / Demesne)—— 增加 Ethereal 计数源;② Time's Up 去消耗 + Eidolon 重做 —— Doom 与 Ethereal 两轴从「一次性兑现」转向「可重复引擎」;③ Borrowed Time 重做 —— 自我代价从自伤转向透支,风险从「血量」转到「节奏」。
对 OneDeck 的参考点:① 条件卡(制造)与兑现卡(消费)的两段式结构;② 桥梁卡的密度决定构筑自由度;③ 「负资源换正资源」作为费用系统的补充维度;④ 条件收益设计为「频率 × 存量」双形态(Haunt vs Soul Storm);⑤ 兑现件从一次性向可重复演进(Time's Up / Eidolon)是延长构筑寿命的常见手段。

0. 设计目标与方向覆盖

卡池构成：现有 71 张（48 保留 + 23 重做）+ 29 张新增 = 100 张。稀有度：25 common / 50 uncommon / 25 rare。新增 3 个流派（沉睡觉醒 / 交换位移 / 攻击武备），均与现有墓地、次元、诅咒、通用流派交叉设计，无孤岛。

六个方向非独立，一卡可多向覆盖。下方 KPI 的「方向覆盖」由数据表自动统计：

  • 方向 1 沉睡机制：新增【沉睡】规则 + 5 张沉睡卡 + 5 张唤醒/喂条件支持卡 + 1 张敌方沉睡控制卡（噩梦）。
  • 方向 2 未选卡重做：23 张从未被选择的卡全部重做，统一改为「定向 + 有收益」。
  • 方向 3 指向性：新增 9 种检索谓词（位置 / Tag / 数值三族），每个流派都有确定性的选目标手段。
  • 方向 4 卡牌移动：新增交换（2 张）、延迟、下 X 张敌方埋葬、最深置顶/埋葬、牌库顶操作等。
  • 方向 5 新 Tag：新增 9 个机制 Tag：攻击者 / 负面 / 沉睡 / 唤醒者 / 力量给予 / 埋葬者 / 置顶者 / 交换者 / 延迟者。
  • 方向 6 新流派：沉睡觉醒（10 张）、交换位移（5 张）、攻击武备（7 张）。

2. 新机制【沉睡】

设计意图（用户方向 1）：① 门槛机制 —— 强力卡必须满足条件才能登场，把「买到就生效」改为「喂条件才有回报」；② 延迟价值 —— 让「晚到更有用」的卡被自然地延迟出场，登场即带着累积的状态。

2.1 规则（R-S1 ~ R-S14）

  • R-S1 入眠：带【沉睡】的卡加入牌库时（购买 / 生成 / 洗牌后）置于 start card 之后（墓地区），进入沉睡状态。
  • R-S2 休眠：沉睡卡不揭晓、不触发自身任何事件与效果（监听器挂起）。
  • R-S3 可交互：沉睡卡仍在 combinedDeckZone 中，可被效果正常选中：可被给予力量（喂条件）、被放逐（硬移除）、被埋葬（埋向更深处，仍沉睡）、被检索谓词选中；计入「友方在墓地」类计数（碎骨聚集体 / 冥界邀请 / 人间大炮 / 被诅咒的骷髅等）——沉睡卡本身就是墓地密度。
  • R-S4 置顶即唤醒：沉睡卡被置顶 = 立即唤醒，置于牌库顶，下一张揭晓登场（触发正常置顶流程）。这是玩家的主动唤醒路径。
  • R-S5 唤醒检查（事件驱动）：每张沉睡卡声明一个唤醒条件（事件 + 谓词）；条件相关事件触发时立即检查。回合结束洗牌时兜底全面检查一次（保证所有条件类型的正确性）。
  • R-S6 唤醒落点：条件满足 → 唤醒，插入「准备位」（start card 前一位，复用现有 Setup 位置），本回合末（start card 揭晓前）正常揭晓并触发效果。兜底检查唤醒的同样插入准备位（下一回合末登场）。落点固定 = 可预期。
  • R-S7 唤醒后的卡：参与后续洗牌，按普通卡运作。
  • R-S8 条件类型：力量类 / 资源类 / 回合类 / 回合计数类（见 2.3）。
  • R-S9 条件状态：回合计数类条件随洗牌重置（与现有 per-round 计数器一致）；力量 / 资源 / 回合类跨回合累计。
  • R-S10 疲劳：沉睡卡不揭晓，不计入 totalCardsRevealed。
  • R-S11 生命（life）：沉睡卡不参与 life / 弹回规则（沉睡期按 lifeMax = 0 处理）。
  • R-S12 中立：start card 与中立卡永不沉睡。
  • R-S13 对称：双方规则一致（异步 PVP 目标）。
  • R-S14 新事件：新增 onMeWoken / onFriendlyCardWoken（守夜人等监听）。

3. 新属性【攻击力】

  • 定义：卡面固有属性 attack（int ≥ 0），与力量完全独立、不随时间变化；力量是临时叠加状态，攻击力是固有数值。
  • 补值规则：攻击力 = 该卡主伤害效果的单段基础值（xN 多段取单段；动态伤害 = 0）；无伤害效果 = 0。现有 48 张保留卡按 Obsidian 卡片库「基础伤害」列补值。
  • 用途：①「攻击者」Tag 判定（attack ≥ 1）；② 检索谓词（最高 / 最低攻击、总攻击）；③ 效果数值来源（如「造成[友方总攻击]伤害」）。
  • 与力量的关系：力量按命中计入伤害 → 攻击者的力量 = 其攻击力的放大器（攻击 × 力量 = 爆发），攻击流派与力量流派天然交叉。

5. 新流派 ×3

5.1 沉睡觉醒（10 张：5 沉睡 + 5 支持）

  • 核心循环：购入沉睡卡 → 用力量给予 / 裂缝生成卡喂条件 → 事件驱动唤醒 → 准备位本回合末登场 → 大效果。
  • 骨架：沉睡的巨像（rare 门槛核心）+ 枕边低语（喂力量）+ 晨钟（唤醒加速）；大觉醒 + 守夜人（爆发层）；噩梦（敌方控制层）。
  • 支持密度：力量给予卡（铁匠、献祭剑、咒食的萨满等）喂力量类条件；次元流（次元虫、坠入裂缝）喂裂缝类条件；墓地流（尸爆、冥界大炮）喂埋葬计数类条件——支持卡池天然存在。
  • 交叉：沉睡卡计入墓地计数 → 与墓地流派互相喂；古代兵器（8 攻）→ 攻击流派核心输出；次元胚胎 → 次元流派大核心；恶魔低语 → 诅咒流派交叉。
  • 稳定性：唤醒落点固定（准备位），登场时刻可预期；条件是确定性谓词，玩家可控。

5.2 交换位移（5 张）

  • 核心循环：直接改写揭晓顺序 —— 交换（自身↔下一张亡语、友方↔敌方攻击者）、延迟敌方、埋葬下 X 张敌方、置顶定向检索。这是本游戏与随机洗牌类游戏的核心差异面：玩家控制顺序 = 减少随机。
  • 骨架：灵魂交换（亡语接力）+ 掘墓人（下 2 张敌方入墓）+ 时光倒流（延迟）+ 传令官（tutor）+ 位置交换。
  • 交叉：灵魂交换 → 亡语引擎（把亡语卡提前触发）；传令官 → 攻击流派前排；恶魔低语 → 诅咒加速（置顶敌方负面）；掘墓人 → 与墓地流派共享埋葬计数。
  • 稳定性：全部位置谓词在揭晓时即可读，零随机。

5.3 攻击武备（7 张）

  • 核心循环：以攻击力数值为核心 —— 宽 buff（所有友方[攻击者]）、补短 buff（最低攻击）、攻击复读（最高攻击）、攻击检索移除（敌方最高攻击入墓）、总攻击终结。
  • 骨架：集结号 + 传令官 + 王牌 + 战争英雄；军火库为引擎。
  • 交叉：力量 × 攻击力 = 爆发（攻击者的力量同时放大其攻击）；置顶攻击者 = 前排；诅咒卡攻击力为 0（负面 Tag 与攻击者 Tag 天然区分）；古代兵器（沉睡流）与亡魂之茧（墓地流）都是攻击核心。
  • 稳定性：攻击力为固有属性，检索永远可读；宽 buff 走全集（MARTYR 模式），不依赖随机选目标。

9. 平衡性风险与开放问题

9.1 平衡性风险（需实测）

  • 增殖的厄运平方风险：复制敌方[负面]到敌方并继承力量 → 敌方诅咒数 × 力量的每回合自伤（二次方增长，prefab 绑定 CopyEnemyCurseCardToThem）；配合恶魔低语 / 恶化增长更快，需实测上限。
  • 宽力量雪球：集结号 / 军火库走「所有友方[攻击者]」全集，力量跨回合持久 → 军火库用「埋葬 1 张友方卡」成本对冲，仍需实测。
  • 沉睡期白卡：沉睡卡在条件满足前是零收益卡位；商店支持卡密度（枕边低语 / 晨钟等）必须够，否则沉睡卡 = 差购买。
  • 回合门槛高方差：古代兵器（第 3 回合）/ 蓄势待发（第 2 回合）在短局中可能完全没用——这是方向 1 的有意设计，但需留意门槛对平均局时的影响。
  • 噩梦双刃：敌方沉睡卡计入敌方墓地计数，敌方墓地流派可能反吃收益。
  • tutor 强度：传令官 / 轮回是确定性检索，强度以构筑刚度为代价（符合 sharpness rule 定价）。
  • 大觉醒 + 守夜人：唤醒全部 + 每次唤醒 +1 力量的联动上限需检查。

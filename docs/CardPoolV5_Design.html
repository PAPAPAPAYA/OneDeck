1. 经济统一:单一攻击力

删除「力量」数值。全池唯一数值 = 攻击力(卡面基础值 + 永久成长),攻击结算 = 攻击力 × 段数;易伤(敌方每段 +1)与「攻击 +N 次」保留。理由:力量与攻击力成长在 v4 中承担同一角色(每段加值),两套授予卡(铁匠系 vs 锻炉系)互为重复;统一后授予卡密度减半、动态攻击力(攻击力 = Y)语义更干净。

1.1 关键词体系(v5)

关键词定义
攻击造成 X 点伤害,X = 卡面攻击力(含永久成长,每段计入);动态攻击力(攻击力 = Y)常态结算
攻击 ×NN 段攻击(每段独立结算)
攻击 +N 次该卡每次揭晓的攻击段数永久 +N(可叠加)——第一乘区授予
攻击力 = Y结算时攻击力实时取 Y(动态攻击力)
+N 攻击力卡面攻击力永久 +N(可叠加)——原「力量」「攻击力成长」合并后的唯一授予形式
增强敌方[负面]/[诅咒] 攻击力 +1(不存在时自动生成 JU_ON)
易伤敌方每段受到的攻击伤害 +1(可叠加,永久)

2. 规则更新

2.1 沉睡机制正式化(含置顶排除)

规则定义
新 沉睡状态沉睡中的卡:① 揭晓时跳过效果结算(不触发,不攻击);② 不能被【置顶】指定(敌我通用)—— 沉睡着在自己的牌库位置稳定待机;③ 不能被埋葬(免疫乱葬坑 / 大范围死亡 / 深埋等)—— 沉睡 = 保护;④ 条件满足后于下次揭晓时唤醒并正常结算(唤醒落点 = 准备位,沿用 v4)
新 敌方沉睡敌方卡同样可被赋予[沉睡]:跳过其揭晓与效果,直到条件满足(如「主人受到 3 次伤害」)唤醒。与友方沉睡共用同一状态
新 去除敌方裂缝移除全池不再有「去除敌方[次元裂缝]」的效果(裂隙窃贼重做,§4.3)—— 玩家不能直接消灭敌方资源;敌方裂缝只能通过其自身生命周期互动
沿用12 卡位上限(仅商店)/ 疲劳节流 / 链系统 / Start Card always bottom
设计意图:沉睡从「友方条件兑现」升级为通用状态(友方蓄力 / 敌方控制 / 稳定性保护);「置顶排除沉睡」保证沉睡卡不被提前拉出(提前揭晓沉睡卡 = 浪费一次揭晓),「免疫埋葬」让安眠(§3.5)成为萦绕卡的稳定化手段。

7. 评估:裂缝置顶 2 友方(指令 14)

7.1 现状

裂缝召唤师(v5 保持 U):去除 1 张友方[次元裂缝]:置顶 2 张友方[攻击者](v5 目标限定为[攻击者])。

7.2 评估

维度分析结论
兑换率1 裂缝 → 2 次置顶 = 2 次「被置顶」事件 + 2 张卡提前揭晓。对照:次元引导者(1 裂缝 → 埋葬 2 敌方[攻击者],控制型)同为 1:2 —— 召唤师(收益型)与引导者(控制型)对等,数值上成立1:2 可用
成本裂缝是可再生货币(生成源密度高:献祭仪式 / 错乱传送术士 / 次元虫),但生成有卡位与节奏成本;去除 = 放弃裂缝的其他兑现(次元兽攻击 / 吞噬者力量)成本真实存在
风险点与「被置顶」事件卡的连锁:1 裂缝 → 2 次置顶 → 能量迸发 / 战术爆破手 / 哥布林冲锋部队各触发 2 次 = 单回合 2 攻击力 + 2 次攻击;若未来出现「单回合多次去除裂缝」的引擎,1:2 会被放大需目标限定
建议① 目标限定为友方[攻击者](防止对任意卡的无差别调度);② 保持 1:2 数值;③ 监控点:若出现裂缝去除引擎(如裂隙窃贼重做后的再生循环),把 1:2 降为 1:2[攻击者] 或 1:1.5限定后放行
结论:裂缝 → 置顶 2 友方在「目标限定 [攻击者]」前提下可用,兑换率与次元引导者对等;主要风险是与被置顶事件卡的连锁爆发,通过目标限定与后续监控控制。

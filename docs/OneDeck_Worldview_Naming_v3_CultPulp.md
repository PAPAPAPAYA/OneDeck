## §0 调性总纲

### 一句话

> 商店是梦——你在魇市里逛摊子,梦里什么都有。战斗是醒来——醒来后的城市里那些东西是真的:现代都市的地皮下埋着一个旧教团,怪异是它的圣徒与显灵。卡名 = 低俗恐怖小说的章节名:每一个名字要么让人不适,要么让人背后一凉,绝不让人发笑。

### 与 v2 的关系

- v2(现代都市怪谈)的"日常中的非日常"路线废止:悬念句卡名机制信号为零、同模子句式扎堆、同机制家族无词汇标记。
- v3 全面转向**古典邪教 + 低俗恐怖(body horror / urban legend 角色)**:名词具体、画面 graphic、恐怖优先,禁止日常反讽与黑色幽默。
- v2 的"零奇幻词根"禁令废止,替换为**词根纪律**(见 §2)。
- "苏醒"的 fiction = **复活后的苏醒**(回来的东西睁眼了),与梦/醒包装无关;梦只属于商店。

### 命名硬规则

1. **恐怖优先**:拒绝平淡意象与蠢萌读感;每个名字必须 graphic、具体。
2. **从 desc 出发**:cardTypeID 仅是程序代号,禁止作为词源。
3. **埋友方 = 中性祭祀意象**:自愿的代价(祭/殉/牲),不带"拉敌人下水"的攻击性读感,且名字需读得出攻击能力。
4. **诅咒系 = 中国古典咒术**(蛊/降头/咒/厌胜);信徒系 = 古典教团(西方邪典职衔与仪式);两系以外允许西方邪典意象(耳语/邪印/倒十字/圣痕/火刑柱)。
5. **稀有度词不进卡名**:卡面稀有度统一为 ✦ 数量,卡名禁止出现红/蓝/星数指代;商店卡只管噩梦氛围。
6. **token 保持机制透明**:信徒 = 信徒,诅咒 = 诅咒。

## §1 实体 / 现象 / 状态 命名句法

| 类型 | 句法 | 读感 | 例 |
|---|---|---|---|
| 实体(生物,能造成伤害) | 名词性主体:角色/怪物/称号 | "这是谁" | 食尸鬼、狂信徒、连体人 |
| 现象(非生物) | 事件句/征兆/物件 | "发生了什么" | 墓园空了、黑弥撒、血契 |
| 状态(诅咒) | 固定家族词根 | "它缠着你" | 蛊/咒家族 |

## §2 词根纪律(半绑定制)

每条机制轴配一个词根库,卡名自带机制归属:

| 轴 | 词根库 | 禁忌 |
|---|---|---|
| 商店(梦) | 魇/梦/夜 | 战斗卡禁用"梦"字 |
| 诅咒 | 蛊/降头/咒 | 不用民俗妖怪名 |
| 信徒 | 教团职衔与仪式:司祭/侍僧/施洗/弥撒/殉道/血飨 | 不用现代传销梗 |
| 复活/苏醒 | 回/招/唤/魂 + 尸变/起尸 | 不用"梦游"类 |
| 埋友方代价 | 祭/殉/牲 | 不带攻击敌方读感 |
| 遗言 | 遗/殓/丧/悼 | — |
| 埋敌方 | 勾/索 | — |

**半绑定规则**(讨论结论 2026-09-08):

1. 词根绑"家族最大公约数":同条件族绑条件词根,同收益族绑收益词根。
2. **浓度上限 60~70%**:每族留 3~4 张纯意象 icon 卡当记忆锚点(黑弥撒、什一抽杀级),铺满词根即成模板,禁止。
3. 交叉卡(同时属两族)取更稀有、更标识构筑方向的一侧词根。例:SACRIFICIAL_SPIRIT 取「殉」,SWARM_CURSER 取教团职衔。
4. 词根的价值是组牌时快速归类,不承担传达完整机制的任务(机制由 desc 承担)。

# 三款主流卡牌游戏的终端设计调研（游戏王 / 炉石传说 / 万智牌）

> 日期：2026-08-22 · 目的：为 OneDeck 卡池的终端设计提供参考
> 「终端」定义：终结对局的卡牌或组合——包括直接胜利、OTK/FTK 斩杀、单回合爆发、终场压制与替代胜利

## 一、游戏王（Yu-Gi-Oh!）

游戏王无费用体系，终端强度由「召唤条件 / 展开链长度 / 检索资源」约束；对局普遍一回合打完 8000 LP，OTK/FTK 是常态而非例外。

### 1.1 特殊胜利（替代胜利）

| 卡名 | 达成条件 | 设计特征 |
| --- | --- | --- |
| 被封印的艾克佐迪亚（黑暗大法师） | 手牌集齐头部 + 四肢 5 部件，直接获胜 | 游戏王第一个特殊胜利；集件型。部件单卡极弱，整副牌为「检索 + 滤抽 + 苟活」服务 |
| 究极封印神 艾克佐迪奥斯 | 墓地集齐 5 种「被封印」怪兽时获胜 | 艾克佐迪亚的墓地变体，把集件区从手牌搬到墓地 |
| 光之创造神 赫尔阿克蒂 | 召唤成功即获胜 | 终极大哥式胜利，素材要求三幻神，达成成本极高；「结算即赢」 |
| 命运之板（通灵盘） | 场上集齐命运之板 + 死之信息 E/A/R/T/H 五张 | 对方回合逐步铺件的拖延型特殊胜利 |
| 最后的倒计时 | 支付 2000 LP，20 回合后获胜 | 纯拖延型，整个卡组只为「活到第 20 个准备阶段」服务 |
| 胜利龙 | 直接攻击使对方 LP 归零时，额外赢得整场 MATCH | 单局胜利升级为整场胜利；已被禁止——越过赛制框架是红线 |
| No.88 机关傀儡-命运狮子 | 集齐 3 个命运指示物时获胜 | 指示物积累型 |
| 毒蛇神 维诺米纳迦 | 集齐 3 个超毒指示物时获胜 | 指示物积累型，蛇神体系终端 |

注：「最后一战（Last Turn）」等规则级特殊胜利卡亦已被禁止。

### 1.2 OTK / FTK 斩杀终端

| 卡名 | 定位 | 关键效果 | 常用斩杀形态 |
| --- | --- | --- | --- |
| 访问码语者（Accesscode Talker） | 泛用链接斩杀 | 召唤时 ATK 上升素材连接标记数×1000；②除外墓地连接怪兽，不取对象、不能连锁地炸卡 | 水机+魔皇后轴 5300；顶配素材 8300；先炸后打完成 OTK |
| 刺刀枪管龙（Borrelsword Dragon） | 泛用链接斩杀 | 同战斗阶段 2 连击；攻击宣言时攻击力取对方怪兽一半 | 高攻翻倍 + 二连击穿防 |
| 超魔导龙骑士－真红眼龙骑兵（红爹） | 融合终端 | 取对象与效果破坏双抗性；②炸怪补伤害；③弃 1 手无效并破坏一次效果发动 | 攻防一体全能终端；2020 限 1 → 禁 1 → 2024 恢复限 1 |
| 闭锁世界的冥神 | LINK-5 解场/斩杀 | 可把对方 1 只怪兽当素材（吃掉大怪）；召唤时对方全场效果无效；只受取对象效果影响 | 配 I:P 伪装舞会莱娜在对方回合加速连接跳出 |
| FTK 体系（异色眼 + 抒情歌鸲-独行夜莺 等） | 第一回合取胜 | 连续效果链在一回合内完成击杀 | 依赖特殊召唤链 + 连续效果，对手还没动就结束 |

共性：单卡爆发「出得来就赢」；达成成本由素材/展开链约束而非费用；斩杀终端普遍带不取对象、不能连锁等反交互设计。

### 1.3 先攻终场压制（终场/压制终端）

- 「终端」在游戏王的另一含义：先攻做出的把对局锁死的终场，如 幻崩场（I:P + 闭锁世界的冥神）、双穹之骑士 阿斯特拉姆（战斗抗性 + 己方战斗不取对象）等
- 特征：不立刻获胜，而是让对手无法正常展开 = 锁定胜势；由「康 / 抗性 / 封锁」三件套构成
- 设计注记：压制终端的强度由「不可交互性」决定，禁限表大量条目属于此类（红爹、幻崩场组件等）

### 1.4 设计特征小结

- 无费用 → 终端强度不由资源税约束，平衡靠禁限表治理
- 爆发密度极高，反交互（不取对象/不能连锁）是斩杀终端的标配
- 特殊胜利存在但几乎不进主流环境：达成条件苛刻 + 强度被规则限制；无条件低成本直接获胜是绝对红线（胜利龙、最后一战均被禁）

## 二、炉石传说（Hearthstone）

炉石有明确的费用曲线（10 费/回合），斩杀线 = 单回合可用费用的函数——这是「斩杀可计算、可被预测」的根源。

### 2.1 直伤法术终端

| 卡名 | 效果 | 设计特征 |
| --- | --- | --- |
| 炎爆术 | 10 费 10 点直伤 | 最纯粹的「费用换伤害」终端 |
| 火球术 | 4 费 6 点伤害 | 中期斩杀组件，可被法强放大 |
| 致死打击 | 战士 4 费 4 伤，英雄受伤时 6 伤 | 条件型直伤，「压血线 → 提高斩杀」的经典写法 |
| 嗜血 | 萨满 5 费，全场随从 +3 攻 | 快攻一波流终端，随从越多越痛 |
| 石化武器 + 风怒 | 萨满经典组合（1 费 +3 攻 × 双倍攻击） | 低费组件拼出 12+ 斩杀的「拼图型」终端 |

### 2.2 冲锋随从终端

| 卡名 | 效果 | 设计特征 |
| --- | --- | --- |
| 火车王里诺艾 | 5 费 6/2 冲锋，战吼给对手 2 只 1/1 雏龙 | 通用斩杀外挂；4 费时代配暗影步/冷血可一回合 20+ 伤，官方削为 5 费——终端削弱的教科书案例 |
| 格罗玛什·地狱咆哮 | 8 费 4/9 冲锋，激怒 +6 攻 | 战士标志斩杀：吼爹 + 怒火中烧 ≈ 12 伤 |
| 库卡隆精英卫士 | 4 费 4/3 冲锋 | 节奏型斩杀组件 |

### 2.3 斩杀配合件（压血线 / 减费 / 复制）

| 卡名 | 效果 | 作用 |
| --- | --- | --- |
| 阿莱克丝塔萨 | 9 费战吼，将英雄生命设为 15 | 压低血线打开斩杀窗口，OTK 卡组通用组件 |
| 索瑞森大帝 | 回合结束手牌费用 -1 | OTK 的「资源压缩器」，让大组合提前一回合启动 |
| 暗影步 / 无面操纵者 / 熔岩镜像 | 回手 / 复制 | 支撑「三进三出」与无限组件 |

### 2.4 OTK 体系

| 体系 | 核心 | 斩杀形态 |
| --- | --- | --- |
| 蓝龙系（术/萨/贼/德） | 玛里苟斯（9 费 4/12，法伤 +5） | 法术直伤放大，常见 26~34 伤 |
| 无限火球法 | 大法师安东尼达斯 + 巫师学徒×2 + 熔岩镜像 | 0 费火球无限刷，回合内无限伤害 |
| 咆哮德 | 自然之力（3 个冲锋树人）+ 野蛮咆哮（+2 攻） | 空场 14 伤，随从越多越痛；2016 年树人冲锋被砍 |
| 机械克苏恩（机克） | 牌库/手牌/战场全空时亡语消灭敌方英雄 | 炉石第三个直接获胜手段——唯一非伤害型胜利 |

### 2.5 设计特征小结

- 费用是终端的「资源税」：10 费上限让斩杀线可计算、可预测、可针对
- 交互窗口明确：嘲讽 / 护甲 / 奥秘 / 回血是对手的拦截层，终端强度 = 穿透这些层的能力
- 平衡手段 = 改费用 / 重做组件 / 退环境（火车王、自然之力、冰枪术）
- 胜利条件几乎不脱离「生命归零」，直接胜利仅机克一系——该设计在 HS 被严格控制

## 三、万智牌（MTG）

MTG 终端形态最丰富：生物一波、咒语烧杀、组合技、替代胜利四大类并存；颜色哲学决定终端形态。

### 3.1 生物战斗终端

| 卡名 | 费用 | 关键效果 | 定位 |
| --- | --- | --- | --- |
| 万世创伤伊莫库 | {15}，15/15 | 施放时额外回合；歼灭 6；飞行、反有色咒语、不能被反击 | 终极生物终端，「落地即接近胜利」 |
| 绝望终局伊莫库 | {13}，13/13 | 施放时夺控对手下个回合；飞行践踏、反瞬间咒语 | 组合技与进攻兼得的控制式终端 |
| 坑蹄巨兽 | {5}{G}{G}{G}，7 费 | 进场：你操控的生物获得 +X/+X 与践踏，X = 生物数 | 「铺场一波」通用终结，EDH 最著名的终结者之一 |
| 棘泽边 | {4}{B}{B}{B}{B}，8 费 | 飞行系命；支付 7 点生命抓 7 张 | 「用生命换资源」，本身不打脸而是喂组合技 |

### 3.4 替代胜利（alt-win，分组）

| 类型 | 代表卡 | 条件 |
| --- | --- | --- |
| 生命类 | Felidar Sovereign / 耐力考验（Test of Endurance）/ 濒死体验（Near-Death Experience） | 40+ / 50+ / 1 点生命时获胜 |
| 牌库类 | 实验室狂人 / 塔萨的先知 / 杰斯（Jace, Wielder of Mysteries）/ 智谋之战（Battle of Wits） | 抽空牌库时获胜；200+ 张牌库获胜 |
| 咒语类 | 神日迫临（Approach of the Second Sun）/ 联军胜利（Coalition Victory） | 第二次从手上施放即胜；五色齐全即胜 |
| 指示物类 | Helix Pinnacle / Simic Ascendancy / Darksteel Reactor / Azor's Elocutors / 史诗斗争（Epic Struggle） | 100 / 20 / 20 / 5 / 20 个指示物或生物时获胜 |
| 资源类 | Revel in Riches / Liliana's Contract / 迷宫的尽头（Maze's End） | 10 个宝物 / 4 个恶魔 / 10 张门时获胜 |

特征：替代胜利是「构筑型设计」——整副牌围绕达成条件运转；多数为娱乐向（生命类、指示物类），少数（先知）打进竞技并被禁/限制。

### 3.5 设计特征小结

- 颜色哲学决定终端形态：红 = 直伤、绿 = 铺场终结、蓝 = 组合技/磨牌、黑 = 生命换资源、白 = 替代胜利与防御
- 替代胜利密度三游最高（30+ 张），胜利条件本身的多样性是 MTG 的差异化资产
- 组合技终端的平衡看「快 / 稳 / 难防」三轴：任何两轴超标就进禁牌表（双生子、先知 + 咨询）

## 四、横向对比

| 维度 | 游戏王 | 炉石传说 | 万智牌 |
| --- | --- | --- | --- |
| 终端形态 | 单卡爆发 OTK / 特殊胜利 / 压制终场 | 直伤 + 冲锋 + OTK 组合 | 生物一波 / 咒语 / 组合技 / 替代胜利 |
| 资源约束 | 展开链 + 检索 + 召唤条件（无费用） | 费用曲线（10 费/回合） | 法术力曲线 + 颜色 + 回合数 |
| 对手交互窗口 | 手坑 / 康（时点交互） | 嘲讽 / 护甲 / 奥秘（斩杀线可预测） | 康 / 解 / 坟场针对（堆叠交互） |
| 直接胜利密度 | 少，且多数被禁 | 极少（仅机克一系） | 最多（30+，多为娱乐向） |
| 平衡调节 | 禁限表 + 新卡克制 | 改费用 / 重做 / 退环境 | 禁牌表 + 赛制分层 |
| 一句话哲学 | 「出得来就赢」的爆发美学 | 「可计算的斩杀线」的资源博弈 | 「胜利条件多样性」的构筑自由度 |

## 五、对 OneDeck 的启示（问题清单）

- 特殊胜利是否入池：游戏王证明「集件型」特殊胜利（艾克佐迪亚式）在无费用游戏中是可行的长线目标；强度红线 = 达成成本与对手的拦截窗口。OneDeck 的逐张揭示流天然适合「条件计数」型（集齐 N 个 X / 累计 Y 次）
- 斩杀线约束：炉石的「斩杀可计算」来自费用上限；OneDeck 无费用，若做爆发终端，约束应来自触发次数、揭示时机与敌方反制，而非资源税
- 胜利面多样性：MTG 的替代胜利提示「胜利条件本身可以是卡池维度」。OneDeck 除敌方生命归零外，是否值得有第二/第三胜利面？（可作为长期差异化方向）
- 压制型终端：游戏王终场压制在 OneDeck 的对应物是沉睡/封锁/降攻类控制；注意「不可交互强度」与娱乐性的取舍

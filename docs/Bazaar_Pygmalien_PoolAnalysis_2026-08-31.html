3. 构筑轴识别

3.1 经济投资轴(身份轴)

Value 累积(Piggy Bank / Business Card) → Sell Price 放大(Abacus) → 卖出回收(Spare Change / Gold) → 收入引擎(ATM / Vending Machine)
入口:Value 增益件(Sell Price 价值提升)。兑现:卖出/回收现金(Spare Change、Gold、Income)。封顶:地产生物(值钱地产)+ 每日收益物件(Vending Machine / Beehive)。
桥:Vending Machine / Business Card / 各类「每日生产」Property。「现金流瀑布」是 Pygmalien 引擎。

3.2 武器护盾摆动轴

28 Hour Fitness(武器→盾 / 盾→武器伤害) → 其它摆动件 → 自循环(使用武器给盾,用盾给伤)
设计特征:Pygmalien 版「自动机」——武器/盾牌互换产生持续缓冲+输出。

3.3 玩具/地产/遗物密度轴

Piggy Bank(玩具,卖价值) → Abacus(工具,价值传递) → 地产(Property 每日收益) → 遗物(Atlas Stone 等)
密度:Toy 40 + Property 40 + Relic 13 ——「逛店/租售」主题,配合买卖经济形成闭环。

3.4 战斗辅助轴(次轴)

特征:Weapon 36 + Heal 50 + Shield 38 —— Pygmalien 有武器格斗件与大量护盾/治疗,战斗输出偏「耐久滚雪球」。

4. 两段式审计(条件制造 → 兑现)

层设计职责代表件tier 观察
入口层(制造条件/供给)Value 累积、Sell Price 提升、每日收益Piggy Bank / Business Card / Vending MachineB/S 为主
兑现层(消费条件)卖出回收、武器盾摆自循环、地产生益Abacus / 28 Hour Fitness / Cash RegisterS/G 为主
封顶层(条件 → 乘区)高价值地产/大件、全局收入引擎Fort / Tournament Arena / 大型 PropertyG/D 集中
结论:Bazaar 的经济轴是「投资—回报」两段式:入口件投资(Value/收入),兑现件回收(Sell/卖出)。Pygmalien 的语法 =「钱生钱」,其 Value/Sell/Income 接口词汇与 StS2 的「垃圾经济学」不同——Pygmalien 用经济兑现金,而不是卡片数。

## 触发时机

| 术语 | 含义 | 引擎状态 | 使用 |
|------|------|----------|------|
| 揭晓时 | 该卡从卡组顶被翻开时。可省略，是最常见的触发 | ✅ | 默认触发，全库通用 |
| 遗言： | 该卡被埋葬时触发。放逐、置顶等其他离场方式不触发 | ✅ | 7 卡（另有多卡以「遗言卡」谓词或「给予遗言」引用） |
| 被置顶： | 该卡被置顶时触发 | ✅ | 0 |
| 被强化： | 该卡攻击力被强化时触发 | ✅ | 4 |
| 友方被强化时： | 任意友方卡被强化时触发 | ✅ | 1（WEAPON_SPIRIT，作「友方生物被强化时」） |
| 敌方诅咒被强化时： | 敌方诅咒被强化时触发 | ✅ | 0 |

| 敌方诅咒揭晓时： | 敌方诅咒被揭晓时触发 | ✅ | 3 |
| 友方攻击时： | 任意友方卡攻击时触发 | ✅ | 1（RELIC_HIVE） |
| 有卡攻击时： | 任意卡攻击时触发 | ✅ | 1（RELIC_ATTACK_HEX） |
| 回合开始： | 每轮揭晓开始前触发 | ✅ | 3 |
| 洗牌后： | 洗牌动画完成、下一张卡进入揭晓区后触发 | ✅ | 0 |
| 苏醒： | 该卡被复活时触发。仅由复活效果引发；置顶、回响回弹均不触发 | ❌ | 7 |
| 友方苏醒时： | 任意友方卡被复活时触发 | ❌ | 1（RELIC_DEATH_KNELL） |

## 目标谓词

句式：`[数量][阵营][谓词]卡`

- 阵营：友方 / 敌方；省略 = 不限阵营。
- 谓词：生物 / 非生物 / 信徒 / 诅咒 / 遗言 / normal / uncommon / rare / 攻击力最高 / 攻击力最低 / 攻击次数最多。
- `【被强化】`（2026-08-28 裁定进规范）：带有被强化标记的卡，desc 带【】书写（ELITE_REVIVER：`复活1【被强化】友方生物`）。
- `除了【X】`（2026-08-28 裁定进规范）：排除式语法，从选择池排除所有带 X 的卡，X 可为 tag 或谓词（WEAKENING_FIELD：`除了【诅咒】，所有生物本回合攻击力-1`）。
- 省略谓词 = 随机选取（已裁定：战斗中无玩家选择点）。
- `自身` = 这张卡；`该卡` = 上一子句的目标（SACRIFICE_WEAKEST、WEAPON_SPIRIT、GRAVE_ROBBER 在用）。

## 数值来源

- 固定值：`强化1友方`
- 自身攻击力：`每有1攻击力，埋葬卡组顶1卡`（MILLBLADE、SWARM_QUEEN、HEXBLADE）
- 计数器：`墓地每有1友方，埋葬1敌方` / `攻击力=本回合放逐的信徒数量`（GRAVE_LANDSLIDE、RIFT_EATER、REANIMATOR、EXILE_BERSERKER、DECIMATION、RELIC_TALLY、DETERIORATION、SWARM_CURSER、RIFT_REAPER 等）。`每X` 只能作数值来源，不能作触发写法（触发一律用标准时机词，2026-08-28 裁定）
- 引用：`攻击力=该卡攻击力`（GRAVE_ROBBER）

## 区域

| 术语 | 含义 |
|------|------|
| 墓地 | 起始卡（start card）之后的区域（deck index < startCardIndex）。被埋葬的卡去这里；是复活的来源区；「触发遗言」「让墓地X攻击」「墓地光环」的目标都在此 |
| 卡组顶 | 未揭晓卡组的顶部，下一张被揭晓的卡。揭示流程总是从卡组顶取卡 |
| 揭晓区 | 当前已揭晓、正在结算的卡所在位置 |
| 放逐 | 移出本局游戏，不可复活；被放逐的卡同时失去所有被授予的效果 |

## 数据库字段

| 字段 | 规则 |
|------|------|
| CARD_TYPE_ID | 英文 SNAKE_CASE，与 prefab 文件名一致；必填，是唯一 Unity 锚点 |
| ATK | 不攻击的卡留空（不是 0）；只有会攻击但攻击力为 0 的卡才填 0 |
| rarity | normal / uncommon / rare（对应 Unity Common/Uncommon/Rare，prefab 目录 0/1/2） |
| 生物 | 生物 / 非生物；生物 = 带攻击属性的卡（含攻击力 0）。不变式：生物 ⟺ ATK 列非空 |
| tag | 轴标记，与 desc 关键词保持同步。现有选项：埋葬 / 遗言 / 强化 / 被强化 / 信徒 / 放逐 / 诅咒 / 苏醒 / 被动 / 复活 |
| Unity 配置状态 | 已配置 / 可直接配置 / 需小改 / 需新机制 |

## 术语统一（硬性规则）

- 只准用：**卡组顶 / 遗言 / 强化**；禁用：牌堆顶、牌组顶、亡语、增强。
- 墓地中的目标永远写「复活」，不写「置顶」；「置顶」只用于从未揭晓卡组拉卡。
- 信徒 = 旧称「次元裂缝」（RIFT token）；诅咒 = 敌方诅咒 token。
- 数字用阿拉伯数字；多段攻击写 `攻击x2`（半角 x）；ATK=0 写在 ATK 列，不写进 desc。

## 规范扩展写法（2026-08-28 裁定，详见 4.0_CardDesc_Spec.md「Extended Constructions」）

以下写法原不在规范关键词表中，经 Q&A 裁定后已进规范：

| 写法 | 裁定语义 | 使用卡 |
|------|----------|--------|
| 触发X的遗言 | 目标必须在墓地；触发后卡留在墓地不移动、不产生埋葬事件 | LAST_RITES、RELIC_DEATH_KNELL |
| 遗言触发两次 | 阈值达成后，本回合内所有友方遗言都触发两次 | RELIC_REQUIEM |
| 给予N[目标]：遗言：… | 授予的遗言本场战斗永久有效（洗牌不失效，被放逐即消失） | DEATHBED_GRANT、RELIC_UNDYING_WILL |
| 交换 | 两张卡卡组位置互换，阵营不变 | SOUL_SWAPPER |
| 让墓地1友方攻击 | 卡留在墓地直接结算一次攻击，触发攻击事件 | GRAVE_PUPPETEER |
| 相邻时 | 每事件检查（任何卡组顺序变化后立即检查）；相邻 = 卡组逻辑索引差为 1 | RELIC_TAINT |
| 墓地中的生物攻击力+1 | 持续光环，含自身；被动卡不可复活、洗牌后固定回墓地，光环实际常驻 | RELIC_GRAVE_LORD |
| 效果变为：… | 永久改写全部信徒（含之后生成的） | RELIC_RIFT_OVERRIDE |
| 攻击不再造成伤害，而是… | 每段攻击独立转化等量强化；攻击事件照常触发 | RELIC_BLOOD_PACT |
| 每复活1友方，… | 不是合法触发写法，统一改写为「友方苏醒时：」 | RELIC_SOUL_TAX（2026-08-28 DB 整理中该行已移除/改名，规则保留） |

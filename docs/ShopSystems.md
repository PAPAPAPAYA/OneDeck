## Duplicate Slot Rule

`ShopManager.duplicateCopiesShareSlotRef` (BoolSO in `Assets/SORefs/ShopRefs/`, default OFF). ON: copies sharing a `cardTypeID` take 1 deck slot (first copy only), stack upper-left in the shop display, and only the stack base shows price (`ShopCardView.suppressPriceDisplay`); count via `UtilityFuncManagerScript.CountCardsTakingUpSpace`; empty `cardTypeID` never deduped; `CombatStartCardGiver` and enemy deck unaffected. Shop empty slots are persistent background objects (`ShopUXManager._spawnedEmptySlots`, one per deckSize grid slot) — never consumed/respawned by buy/sell; `_spawnedPlayerCards` holds real cards only; buy/sell just add/remove + `RelayoutPlayerDeckCards()`. Plan: `plans/plan-duplicate-cards-share-deck-slot-2026-07-31.md`.

## Shop Utility Passives & Board Pipeline

Plan & execution state: `plans/plan-utility-passive-shop-pipeline-2026-08-31.md` (§6); probability + mixed-pool rework 2026-09-11: `plans/plan-shop-utility-probability-mixedpool-2026-09-11.md` (§5).

- Metadata: `CardScript.utilityKind` (+ `utilityValue`/`utilityValue2`/`utilityRarityWeightMults`/`reservedTag`); `IsUtilityPassive` = isPassive && kind != None. `utilityValue2` carries the per-board roll chance % for RaritySlot / ReservedTag / Odds / RerollDiscount kinds (≤0 → default 25 via `UtilityShopBonus.ChanceOrPercent`; cadence semantics retired 2026-09-11). ShopOptionChance (2026-09-14): `utilityValue` = slots added on a hit, `utilityValue2` = per-board chance % (≤0 → 25); `bonus.extraBoardSlots`/`extraBoardSlotsChancePercent` grow the generic slot count on a per-board hit, both modes, both board types (card: UTILITY_OPTION_P_1 魇市游摊; unconditional sibling OPTION_1 魇市新摊 moved to Uncommon same day). Passive utility = deck-resident, slot-free (`occupiesDeckSlot` = false, 2026-09-14: buy-capacity check skipped) but physical (`physicalDeckCard`, renamed from `takeUpSpace`: deck-band display, sellable, combat-instantiated per 2026-09-14 ruling A), sellable (sell removes it); all bonuses are RECOMPUTED from the deck — no accumulating listeners.
- `UtilityShopBonus` (pure static) derives all from `playerDeckRef`: baseline growth (payday/hpMax/deckSize step growth = `growthPerStep * floor(session / sessionsPerStep)`, interval 1 = legacy every-session slope), per-kind effects, owned dedup. Sole stateful exception: deck-slot meter card — `DeckSizeIncreaseEffect` bumps run counter `DeckSlotPurchasesRef` (reset in `PhaseManager.ResetRun`), self-exiles on buy (BuyFunc skips deck add), escalating price, capped by static `maxDeckSize` (16).
- Shop HP invariant: `ApplyHpMaxFromDeck` (entry/buy/sell) sets `hp = hpMax`; shop phase is always full HP, so combat starts full (`HPMaxAlterEffect` removed 2026-09-04).
- `ShopBoardPipeline.GenerateBoard` (pure static, injected System.Random): pool classification (owned-utility dedup + deck-size ceiling exclusion baked in) → MIXED mode (default, `ShopManager.splitUtilityCombatBoards = false`): `MergePools` (OddsUtility reference-dedup) then wave filters on the merged pool, no board-type roll; SPLIT mode (legacy): board-type roll (`sessionUtilityBoardChances`; empty utility pool → combat board) → wave on the chosen pool only. Both: weighted generic rolls (session table × shopRollWeightMultiplier × RarityWeight mults) → reserved slots appended last, never displacing generic slots (per-board independent chance roll, no cadence/pity; `firstBoardOnly` = ODDS deep form, board 0 only, skips the roll; candidates: mixed = merged pool, split = classified pool, utility promises (`wantsUtilityCard`) always from the utility pool; utility-board drought → any-rarity fallback, otherwise skip on empty). `CurrentBoardIsUtility` is only meaningful in split mode (drives the 奇物架 UX marker).
- Board discounts (`ShopManager.ApplyBoardDiscount`, called from EnterShop AND Reroll): every discount spec rolls its chance once per generated board (initial board included); on a hit ONE random board card gets `UtilityShopBonus.GoldOffForPercent` (half price rounds UP), struck-through display via `GetBoardDiscount`, settlement via `GetEffectiveBuyPrice`; the per-board dict is cleared on every generation (no accumulation across boards).
- Stats: result rows and `CountGraveyardCardsOf` exclude `IsUtilityPassive` (latter: no enemy GRAVE_CURSE feed); deck-population axis still counts passives; ShopStatsManager logs utility appear/buy share.

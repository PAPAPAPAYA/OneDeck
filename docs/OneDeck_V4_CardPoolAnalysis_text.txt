核心循环
:Shop → Combat → Result;双 deck(玩家 + 敌方)合并洗牌,一卡一卡揭晓,Start Card 沉底并触发洗牌。
三个动作即全部语法
:
揭晓
(结算卡面效果,卡进墓地)、
置顶
(插队提前揭晓,触发「被置顶」事件)、
埋葬
(把卡从牌库送进墓地:送走敌方 = 控制,埋葬友方 = 触发亡语 + 喂墓地)。无费用系统 —— 与 StS2 五角色全部依赖能量/星币形成根本差异。
结构规则
:12 卡位上限仅限商店;combat 生成卡不受限(史莱姆/诅咒/裂缝可增殖);疲劳(总揭晓数)为天然节流阀;链系统(同卡同效果一链一次 + 深度 99)保证无真无限。
数值经济
:攻击 = 卡面攻击力 + 力量(每段计入);第二乘区三形态:力量(通用)、攻击力成长(定向,卡面 +N)、易伤(敌方每段 +1)。
双 deck 合并 = 独有维度
:敌方卡是可被操作的资源 —— 增强敌方[负面]/[诅咒](种诅咒)、去除敌方[次元裂缝](抢资源)、无差别埋葬(掀桌子)。StS2 无对应物,这是 OneDeck 的差异化资产。

结构性结论:
U 层 51% 是 v4 与 StS2 的最大稀有度差异
—— 中间层组件密度极高(事件自动机 + 轻兑现 + 桥),而 Rare 封顶层只占 22%。结合 §2.3 审计:U 层干净(无重转换混入),问题在 R 层「封顶体验稀疏 + 形态升级为零」;以及 Common 层 3 张沉睡教学卡(浅眠者 / 春眠 / 枕边低语)违背「入口层即打即用」(设计总结 P2-1)。

7. 设计观察
三动作语法 = 无费用的节奏经济
:StS2 五角色的货币(能量 / 星币 / 球 / 弃牌)在 OneDeck 全部缺席,等价物是「节奏」(置顶 = 免费再触发)与「存量」(墓地 / 裂缝 / 诅咒力量)。置顶-被置顶事件对(Silent 弃牌-Sly 对)是全池的触发密度来源 —— 这套语法自洽且与 StS2 完全不同,是 OneDeck 的结构性优势。
双 deck 合并 = 独有维度
:敌方卡是可操作的资源(增强敌方[负面] / 去除敌方裂缝 / 无差别埋葬 / 敌方诅咒揭晓触发)—— StS2 五角色全部没有。这既是差异化资产,也是「敌方降力 / 处决 / 敌方沉睡」等缺口存在的原因:这些维度在 StS2 是标配,在 OneDeck 还未长出。
位置谓词是 OneDeck 独有的定向语言
:(最高攻击 / 最低攻击 / 最深 / 下 2 张 / 力量最多)—— StS2 的同类效果几乎全是随机或玩家选择。位置谓词把「调度」变成可预测的策略深度,是 v4 最被低估的设计。
力量胶水 44%
:与 StS2 一致(力量 / 敏捷 / Focus 同为最大胶水);第二乘区三形态(力量通用 / 攻击力成长定向 / 易伤敌方侧)+ 次数授予,结构上比 StS2 更完整。
稀有度结构差异
:U 层 51%(StS2 42%)—— 组件与事件自动机密度全游最高,代价是 R 层仅 22%,封顶体验稀疏;且事件自动机(24 张)与回合自动机(0 张)比例失衡。
三大缺口(详见设计总结 §2.2 / §2.3)
:① 击杀兑现(Fatal)缺失 —— StS2 四角色全有;② 回合开始自动机为零;③ 形态升级型为零(数值放大有,触发次数 / 群伤化 / 载体全局化无)。另有诅咒 × 沉睡轴桥空位。
宽容的失败成本
:沉睡喂料卡全部带兜底(晨钟 / 枕边低语无沉睡卡时不白板)—— 比 StS2 的「零贡献期」(Wraith Form 减敏捷 / Borrowed Time 全卡 +1 费)更宽容,代价是极值上限略低。这是设计取向的选择,不是缺陷。
对照结论:OneDeck v4 的骨架(两段式 / 多乘区 / 桥网络 / 无上限自限)与 StS2 成熟结构一致,且拥有 StS2 没有的双 deck 维度与位置谓词语言;主要改进空间集中在「Rare 封顶体验」(形态升级 + 裂缝封顶)、「击杀兑现」与「回合自动机」三个方向(落地清单见设计总结 §5)。

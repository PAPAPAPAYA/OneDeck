## §0 调性总纲

### 一句话

> 城市照常运转。写字楼、居民楼、便利店、末班车。但在日常的缝隙里,有些东西在不对的位置、以不对的状态存在着——门上贴着的保险书、香火不断的野庙、多出来的第十三张床。你的牌库就是这些"存在"的清单;对面也一样。它们被埋葬、被复活、被强化——用最平淡的说法,做着最不平淡的事。

### 与 v1 的关系

- v1(新怪谈·都市怪谈·邪教)名义三支柱平行,实际机制层被邪教词占七成;4.0 的 desc 已 7/7 架空 v1 机制词表(埋葬≠献祭、置顶≠请出、揭晓≠降临、生成≠招募、强化≠加深、复活/苏醒≠活化)。**v2 不再继承 v1 的机制改名,以 4.0 现行白话机制词为永久基线。**
- 邪教、民俗怪谈、新怪谈在 v2 中是**平行赛道**,共享同一个当代现实,异常藏在不同的日常缝隙里。没有统摄主题。

### 命名规则

1. **从 desc 出发,不看 cardTypeID**(代号会把人带向奇幻模板)。
2. **日常中的非日常**:名词具体、画面自足、自带疑问。恐怖藏在"完全正常的词描述不正常的事"的错位里。
3. **零奇幻词根**:魂/灵/咒/祭/圣/魔等古风词根原则上不用(机制词除外,机制词本来就不在卡名里)。
4. **同构不强制**:机制同构提供爽感,纯形象(天蛾人式怪人)提供 icon 与记忆点,两者混编。
5. **字数跟着画面走**:2~9 字皆可,不设死规则。

### 五赛道

| 赛道 | 手法 | 代表 |
|---|---|---|
| 场景/物件 | 平常物 × 不平常的行为;物件出现在不该出现的位置 | 贴在门上的保险书、停电、洗不掉的印子 |
| 死亡意象 | 悬念修饰语:矛盾状态/数字越界/不该持续的进程/被擦除的痕迹 | 还留着体温的空床、多出来的第十三张床 |
| 都市怪人 | 职业/身份/被目击者口吻,不强绑效果 | 哭灵人、收尸人、递请柬的人 |
| 怪物演绎 | 不翻译怪物本体,翻译其恐怖内核在现代都市的对应物 | 医学院的标本、管道里的活物 |
| 民俗恐怖 | 白事物件的都市错置;民俗规则在现代社会依然执行 | 一对纸人、抬上楼的纸别墅、楼下的叫魂声 |

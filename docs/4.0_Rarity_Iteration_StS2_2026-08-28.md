# 4.0 Card Database 稀有度迭代（基于 StS2 结构 + 强度判断）

日期：2026-08-28（同日删并落地后更新）
数据源：Notion「4.0 card database」（109 行 = 89 启用 + 3 备用 + 17 已删）
依据：docs/StS2_DesignSynthesis_ForOneDeck.html（§1.1 稀有度=学习路径、§1.6 三分法、§2.3 桥与转换件审计）

## 1. StS2 稀有度阶梯（取自设计综合文档）

| 层 | StS2 结构要求 | 证据 |
|----|--------------|------|
| Common | 即打即用、零成长承诺、无能力卡、无零贡献期；入口层只教「制造条件」 | 五角色 Common 能力卡数均为 0 |
| Uncommon | 组件与桥梁密集区：制造桥（C+U）、轻兑现（单次小值）、轻引擎（事件自动机）；允许双投制造桥 | 跨轴桥 9-13 条/角色大部分落 U |
| Rare | 封顶件（存量×N 大数字）、重转换（引擎型/形态升级）、轴间合并 | 处决、Bury 52、Reaper Form、Soul Storm 等 |

例外规则：基础资源兑换可放 Common（Body Slam：格挡→伤害）；体系资源（毒/Doom/星/球）的兑换才需要 U/R 梯度。
OneDeck 审计要点（§2.3.3）：U 层不得混入封顶型/全局引擎型；R 层 = 封顶 + 引擎 + 形态升级。

## 2. 本迭代的分级判据（= StS2 阶梯 + 强度判断）

- **normal（即打即用教学层）**：单效或「攻击 + 1 单位资源」制造桥（对照 Reave/Blight Strike/Pommel Strike）；基础兑换（埋葬→攻 = Body Slam 例外 1）；小数字、无引擎、无成长承诺、无大上限。苏醒/遗言仅作小额条件赠益（非零贡献期）。
- **uncommon（组件/桥/轻引擎层）**：双投制造桥；轻兑现（放逐 1→x3、回合计数攻击力、1:1 存量→攻）；轻引擎（事件自动机，单次小收益：信徒揭晓→埋葬顶、被强化→成长、敌方诅咒揭晓→复活自身）；计数兑现（本回合放逐数→段数）；谓词复活/复辟组件（最高攻击/被强化/rare 谓词）；控制件（延后/交换/群降攻）；小收益回合自动机。
- **rare（封顶/引擎/形态升级层）**：
  - 封顶型：放逐所有信徒、埋葬所有友方、墓地每有 1 卡埋葬 1、每有 1 信徒强化、每有 1 攻击力→X（自我成长×N）、复辟+大数值复合卡；
  - 引擎型（全局/系统级）：每次攻击→生成、埋葬→生成、复活→强化诅咒、诅咒攻击次数+1、攻击不再造成伤害改强化诅咒、信徒效果重写、敌方诅咒攻击力=墓地数量、墓地生物攻击力+1；
  - 形态升级/复制：遗言触发两次、苏醒触发遗言、触发其他友方遗言、复制自身、攻击力翻倍、攻击x4（次数阶梯顶值）。

## 5. 关键分档说明

1. **动态攻击力三档**：回合计数（本回合复活数/放逐数）→ U（瞬时、上限 ~5）；永久存量 1:1（墓地友方数、敌方诅咒攻击力、复制最高攻击力）→ U（轻兑现，对照 Haunt 的 Soul→伤）；自我属性 ×N（每有 1 攻击力→信徒/磨牌/强化）→ R（需 强化 成长支撑，是集中成长兑现）。
2. **轻引擎 vs 全局引擎**：单次小收益事件自动机（信徒揭晓→埋葬顶 1、友方被埋葬→埋葬顶 1、被强化→+1）→ U；系统级/全轴自动机（每次攻击→信徒、每次埋葬→信徒、每复活→强化诅咒、诅咒攻击次数+1）→ R。判据 = 单次收益是否 ≥ 轴资源 1 单位且不重写全局。
3. **复辟分档（2026-08-28 合并后）**：复活攻击力最高敌方 与 复活敌方诅咒 合并为单轴（成员 54/65/70/80/85，2U+3R）。删并后族内不再按「纯复辟/复辟+大数值」分级——4 张同核心 R 已删至 2 张（65/85），U 层保留 54/70/80 作为复辟组件位。
4. **回合自动机**：小稳定收益（强化最低友方、自埋生成）→ U（StS2 对照 Infinite Blades/Noxious Fumes 为 U）；授予强效（每回合授"遗言：复活自身"）→ R。
5. **次数阶梯**：x2=normal、x2+双效/uncommon、x3（带消费）=uncommon、x4=rare（成长乘区顶值）。
6. **改动既有值仅 3 处**：SPIKE_SKELETON U→C（遗言教学，即打即用）；GRAVE_TOGETHER C→U（埋葬 2 敌方=双倍移除）；RIFT_TWINS C→U（双倍生成）。其余 20 个既有配置全部保留，验证了原配置与 StS2 阶梯一致。

3. 构筑轴识别

3.1 转化引擎轴(身份轴)

Reagent 生产(Catalyst / Alembic / Retort 每日) → Potion 转化(Alembic / Potion Distillery 把左件变药剂) → 类型累积(Cauldron / Vat of Acid 获得物品类型) → Regen 乘区(Secret Formula 把 Regen 转毒/烧)
入口:Reagent / Catalyst 每日生产件。兑现:Potion 使用与转化(Recycling Bin 用后变新药剂)。封顶:类型复制(Mirror 复制左件 / Vat of Acid 按类型倍毒烧)、Regen 大乘区(Secret Formula + Soul Ring)。
桥:Cauldron(类型累积→毒/烧)、Laboratory(附魔+充能遗物)、Potion Distillery(药剂充能+转化)。「炼金流水线」是 Mak 引擎——输入试剂,输出毒/烧/药。

3.2 遗物轴(身份标签)

Relic 混合件(48 件全游最多)→ 遗物充能(Laboratory / Pendulum)→ Regen/附魔乘区
密度:Relic 48(34%)—— 遗物不是独立流派而是「混合载体」,几乎都带毒/烧/转化/附魔之一。

3.3 毒/烧状态轴(输出方式)

Poison 46 + Burn 27 → 状态武器(Plague Glaive / Runic Blade)→ 状态乘区(C.O.R.A 类敌毒→伤 / Secret Formula Regen→毒烧)
特征:毒/烧是 Mak 的主要输出形态,但多作为「附带的第二效」而非主轴——真正主轴是转化。

3.4 工具/地产辅助轴(次轴)

特征:Tool 24(转化件载体)+ Property 9(实验室/图书馆类全局)。工具承担「炼金设备」角色。

4. 两段式审计(条件制造 → 兑现)

层设计职责代表件tier 观察
入口层(制造条件/供给)试剂/催化剂生产、类型累积Catalyst / Alembic / Retort / CellarB/S 为主
兑现层(消费条件)药剂使用/转化、状态武器、Regen 转输出Recycling Bin / Plague Glaive / Secret FormulaS/G 为主

结论:Mak 的两段式是「流水线式」:入口件生产原料(试剂/催化剂),兑现件转化与消费(药剂/类型累积),乘区(Regen/类型数)放大输出。转化接口词汇(Transform/Reagent/Potion)是 Mak 的最小语法单位——比 StS2 的「垃圾经济学」更接近 OneDeck 的「制造条件→兑现」结构(见 §6)。

6.2 OneDeck 落点(初筛)

Bazaar 观察OneDeck 可借鉴不可搬
试剂→药剂→催化 流水线(29 件转化)OneDeck 的「制造条件→兑现」结构与其同构——OneDeck 的复活/信徒生成链可对照「流水线」设计:原料卡→转化卡→封顶卡每日生产(At the start of each day)不映射轮次制

类型累积(Cauldron / Vat of Acid)OneDeck 的「类型谓词」已有——可参考「按拥有类型数倍率」的累积感—
遗物混合载体(48 件)OneDeck 无遗物系统——参考其「遗物不是流派而是载体」的密度设计遗物概念本身不搬
